# ring-control-panel —— 材质参数实时控制器(统一圆心+实时面板)

给「**控制空物体 + 自定义属性 + 材质节点驱动**」这套体系配一个可复用的实现:
把任意一个材质重建为 **XZ 径向同心圆扩展灯** 管线,所有参数(圆心/速度/密度/强度/纯色/开关)
统由一个控制空物体接管,再注入一个 **3D 视口边侧栏实时面板**,拖动滑块即时生效。

## 场景

- 多个材质(同属一个体系)想**共用同一个圆心**发同心圆,像一整道波从中心向外扩散;
- 希望 `速度/环密度/发光强度/纯色亮度/渐变开关` 都能在一个面板里拖动,**实时**看效果;
- 重启后不希望面板和控制失踪,要**挂在工程文件里自动恢复**。

## 用法

```bash
python send.py build_ring_controls.py     # 经 socket 桥远程执行
# 或在 Blender Scripting 工作区 Run Script
```

`build_ring_controls.py` 顶部常量可改:
`MAT_NAME`(重建的材质)/ `CTRL_NAME`(控制空物体)/ `PREFIX`(节点名前缀)/ `PANEL_FILE`。

效果:
- 场景出现控制空物体(默认 `主装置_圆环控制`),5 个自定义属性:
  `speed` 扩散速度、`density` 环密度、`gain` 发光强度、`solid` 纯色亮度、`gradient_on` 渐变开关(1 渐变 / 0 纯色);
- 目标材质重建为:纹理坐标(共用圆心=控制空物体)→ 取XZ → 径向半径 → ×环数 − 扩张 → FRACT → 渐变 → ×强度 → 与纯色按开关混合 → 自发光;
- 5 个驱动全部指向控制空物体,`扩张` 用 `(frame-1)*speed` 驱动、按键播放即扩散;
- 3D 视口按 N → 侧边栏 **「圆环控制」** 分类出现实时面板。

## 关键点(实战踩坑)

- **共用圆心**:所有材质的 `纹理坐标.Object` 设为**同一个控制空物体**,动它就整体对心;
- **改速度没反应**:Blender 5.2 里自定义属性改动**不自动触发材质驱动重算**(脚本内改值驱动不变)。
  正解 = `ctl.update_tag()` + `bpy.context.view_layer.update()`;面板的 draw 里检测值变化后自动调用,
  所以**拖面板滑块即时生效**;
- **重启后面板失踪**:面板是运行期注册,不持久。把面板脚本(本目录 `ring_control_panel.py`)
  作为文本块放进 .blend 并勾 **Register**(`use_module=True`)+ 开 **Auto Run Python Scripts**,
  build 脚本已自动注入;保存后重启自动恢复(实测)。
- 桥 exec 时 `__name__` 是 `builtins`:脚本直接调用 `main()`,不用 `__main__` 守卫。
