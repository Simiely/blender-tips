# 车辆速度系统与刹车收尾 · 脚本包

给「车在跑」的镜头做一套**可调**运动：一条速度曲线决定一切，改档位不用重对构图。

配套文档：[`docs/车辆速度驱动与刹车收尾.md`](../../docs/车辆速度驱动与刹车收尾.md) ·
作业规范：[`skills/blender-vehicle-speed-brake/`](../../skills/blender-vehicle-speed-brake/)

## 文件清单

| 文件 | 作用 |
|---|---|
| `set_speed_curve.py` | 用一张 `KEYS` 表**重建速度倍率曲线**（含刹车拐点）。`MODE='report'` 只读预览 |
| `bake_speed_to_translation.py` | **积分 → 烘焙位移 → 重建相机补偿**。`MODE='report'` 只算不写 |
| `body_dive_param.py` | 建「点头曲线 + 点头强度」并驱动车身俯仰；`MODE='clearance'` 实测穿模上限 |

三个脚本都可以反复跑；`MODE='report'` 与 `clearance` 全程只读。

## 标准动作（顺序不能乱）

```python
# 1) 先在场景里确认现状（只读）
MODE = 'report'                 # set_speed_curve.py
# 2) 写曲线
MODE = 'apply'
# 3) 必须重烘焙，否则画面不动
MODE = 'apply'                  # bake_speed_to_translation.py
# 4) 另起一次请求核验（末帧构图 / 零滑移 / 静帧段）
```

> **改曲线 ≠ 改运动。** 位移是从曲线积分出来再烘焙成关键帧的，不跑第 3 步看起来"什么都没发生"。

## 为什么位移要烘焙、轮角要派生

```
速度曲线 ──积分──► 位移（烘焙, LINEAR）
                      └──派生──► 轮角 -(X0-x)/R    （任何曲线下都零滑移）
                      └──互补──► 相机补偿 (D-REF×∫total)×进度  （末帧构图守恒）
```

- **轮角不要单独打关键帧**：独立的关键帧一旦速度曲线变了就打滑。派生写法永远对。
- **`R` 取「轮心 z − 地面 z」**，不是包围盒半径。包围盒半径会把沉入地面的那几毫米算进去，
  `Δx/Δθ` 会恒等于错误值，看着"很一致"其实每帧都在滑。
- **相机补偿按最终位置算**，`进度` 是 0→1 的 S 曲线、终点饱和为 1，所以**最后一帧构图自动回到原方案**。

## 两个必须知道的坑

1. **`REF` 必须是常量**（`D / 原方案帧数`）。写成 `D / (F1 - F0)` 的话，区间一变长
   （比如尾部接了 15 帧刹车），前面已认可的段会被整体压缩，静默改掉用户的成果。
2. **自定义属性的 min/max 会钳制取值**。内部曲线属性给 `max=0.00` 时，往里写 `+0.0045`
   读出来是 0，而 `fcurve.evaluate()` 是对的 —— 症状是"某个动作整体消失但曲线看着正常"。
   内部属性一律留宽（±0.10）。

## 刹车「顿一下」怎么调

起刹关键帧做**斜率拐点**：进柄水平、出柄猛压。本例逐帧倍率下降量在 f92→f93 从 −0.0048
跳到 −0.1127（23 倍），减速度 −0.3 → −7.4 m/s²。

行程有硬上限：15 帧 = 0.5 s，`行程 ≈ REF × 0.5 × 起刹倍率`。

| 起刹倍率 | 刹车行程 | 峰值减速度 |
|---|---|---|
| 0.80 | 39.6 cm | 8.02 m/s² |
| **0.68** | **32.4 cm** | **7.4** |
| 0.55 | ≈26 cm | ≈6.5 |
| 0.10 | 2.8 cm | 1.6（软，实测被用户否掉） |

## 车身点头

`控制_车身["点头曲线"] × 控制_车身["点头强度"]` → 驱动 `绑定_车身.rotation_euler[1]`。
拆成两个属性是因为**一个属性不能既有关键帧又被驱动**。

- 轴心要在轮轴高度，否则像"整车往前栽"
- 非等比 scale 下动 rotation 安全（`matrix_parent_inverse` 里的 `S⁻¹` 会抵消），但要做**保距校验**；动 scale 会拉开车身
- **强度是相对系数**：改了基准曲线峰值，同一个强度对应的角度全变，`K_MAX` 必须按新基准重测间隙
- 量间隙时轮胎顶点**必须每帧重取世界坐标**，否则全是 0.0x mm 的假穿模
