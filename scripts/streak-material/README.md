# 滚筒斜纹材质（可复用包）

圆柱面上的**螺旋斜条纹发光材质** —— 条纹斜着沿柱身流动（右下→左上），理发店滚筒那种灯柱效果。
含**两套并列的调参方案**（按条数 / 按角度），跑哪个装哪个。

## 一句话原理

斜纹 = 柱面坐标上的**线性相位取模**；波形（快升慢降的"流星感"）另走 **Math 域**，两者解耦。

```
u = (atan2(y, x) + π) / 2π          绕柱角度归一化（y 分子 / x 分母）
v = z / 柱高                        高度归一化（锚点在柱底面 ⇒ 天然 ∈ [0,1]）
f = u×K − (v + 上升偏移)×N          ← SUBTRACT 决定条纹是 `/` 形
p = FLOORED_MODULO(f, 1)            ← 必须 FLOORED，普通 MODULO 会把条纹底部裁掉

前缘 = MapRange(SMOOTHSTEP,  0 .. A  →  0 .. 1)      A = 前缘宽度
拖尾 = MapRange(SMOOTHSTEP,  B .. 1  →  1 .. 0)      B = 拖尾起点
mask = MINIMUM(前缘, 拖尾)                            ⇒ 快升 / 平台 / 慢降
mask → ColorRamp（配色）→ Principled BSDF.Emission Color
```

**为什么波形不放 ColorRamp**：用颜色节点的色标位置去编码一条数学曲线，
参数会互相耦合（改一处动三处）、色标被驱动锁死（用户拖不动）、
拖尾长度被结构卡住（旧做法上限只有 58%）。拆开之后：
参数正交、色标可自由编辑、拖尾能开到 99%。

## 两套并列方案

| | **A · 按条数** | **B · 按角度** |
|---|---|---|
| 材质 | `..._滚筒斜纹_按条数` | `..._滚筒斜纹_按角度` |
| 槽位 | 1 | 3 |
| 控件 | 条纹数量 K + **高度周期数 N** | 条纹数量 K + **斜角** |
| 节点/连线 | 18 / 20 | 22 / 25 |
| 斜角 | 由 K:N 算出 | 直接给，`N = K×(柱高/周长)÷tan(斜角)` |

两者**共用同一个锚点空物体**（纹理坐标必须指向同一个），所以**不要长期并存**
—— 会让控制空物体上留下对方用不到的"幽灵参数"。
**跑哪个装哪个**：装 A 时自动清掉 B 的材质/槽位/键，反之亦然。另一方的建脚本始终保留。

## 实测数据

**运动方向**（固定高度一行的暗带中心跨帧比对；纸面推导曾推反，以实测为准）：

| 驱动表达式 | 两帧间暗带位移 | 结论 |
|---|---|---|
| `−fr * us` | `+0.29 / +0.32`（右移） | ✗ |
| **`+fr * us`** | **`−0.32 / −0.29 / −0.28 / −0.19 / −0.21 / −0.31`（左移）** | ✔ 右下→左上 |

**斜角 ↔ 高度周期数**（方案 B，固定 K=3）：20°⇒N4.75 · 30°⇒N2.99 · **41°⇒N1.99** · 60°⇒N1.00 · 75°⇒N0.46

**端到端波形验证**（φ 空间剖面 vs 独立重算的理论 mask）：**相关系数 0.9989**，亮区区间逐段吻合。

## 复用时要盯的三件事

1. **锚点空物体**必须 `rotation = 0 / scale = 1`，位置 = 柱轴心 + 底面高度 —— 一动整套坐标就偏
2. **端盖**要按**法线**分到独立纯黑槽：端盖上 `atan2` 是极角，条纹投影上去会摊成 K 个扇形（俯视像风车）
3. **隔离临时场景渲染时节点树驱动不被求值** —— `evaluated_get()` 读到的全对、渲染却是旧默认值。
   诊断脚本要么改 ctrl 的值触发，要么把驱动整个移除后手动烘 `default_value`
