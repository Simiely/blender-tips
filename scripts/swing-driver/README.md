# swing-driver · 参数化摆动驱动(单物体 · 参数挂在对象自身)

给一批对象各挂一套「来回摆动」驱动:**最小角度 / 最大角度 / 持续时间 / 相位偏移**
四个滑块长在**对象自己身上**,每个对象各一套、互不干扰,改滑块实时生效,无关键帧、无烘焙。

完整原理、**与主题 46 的适用情况对照**、实测数据见
[`docs/参数化摆动驱动系统.md`](../../docs/参数化摆动驱动系统.md)。

> 选型速记:**群体「时而错开时而整齐」→ [主题 46](../spot-bloom-swing/);
> 个体「各摆各的、参数随对象走」→ 本包;
> 「烘进时间轴、不依赖 Python 权限」→ Skill `blender-loop-keyframe-anim`。**

## 前提

- 目标对象已存在(本项目是空物体父级,下挂一批网格;直接转它网格就跟着走)
- 走 9877 桥执行:脚本**没有** `if __name__ == '__main__'` 守卫
  (桥端 `__name__` 是 `builtins`,加了守卫会**静默不执行**)

## 两步走(顺序不能反)

```bash
python send.py build_swing_driver.py     # 1. 挂参数 + 挂驱动
python send.py verify_swing_driver.py    # 2. 独立核验(必须另一次请求)
```

★ **第 2 步必须另起一次请求**。驱动**只写 evaluated 数据**,同一次 exec 内改完立即读会读到
未刷新缓存值;核验必须走 `obj.evaluated_get(depsgraph)`。

## 配置(两个脚本顶部要勾稽一致)

| 配置 | 含义 |
|---|---|
| `OBJS` | 要挂驱动的对象名列表 |
| `AXIS` | 旋转轴:`0`=X / `1`=Y / `2`=Z |
| `PHASE_STEP` | >0 时按顺序给每个对象递增 `相位偏移`,自动错开(`i × step`) |
| `DEFAULTS` | 参数键名(=显示名)、默认值、min/max、说明 |

## 参数(改完实时生效,不用重跑)

构建后选中对象 → 属性面板 → 自定义属性:

| 属性 | 默认 | 含义 |
|---|---|---|
| `最小角度` | -5.0 | 摆到下死点的角度(度) |
| `最大角度` | 5.0 | 摆到上死点的角度(度) |
| `持续时间` | 100.0 | 一个完整来回 = 一个周期(帧) |
| `相位偏移` | 0.0 | 整体前后挪帧;0 = 帧 1 到达最小角 |

## 脚本清单

| 脚本 | 作用 |
|---|---|
| `build_swing_driver.py` | 主构建:建/刷新 4 个滑块属性 → 清同通道旧驱动 → 挂 `SCRIPTED` 驱动。**幂等**;若目标身上已有关键帧动画,会先摘 action 并改名 + `use_fake_user` 留成孤儿(可回退,**不删数据块**) |
| `verify_swing_driver.py` | 独立核验:逐帧与**手算期望值**比对、周期一致性(`f` vs `f+dur`)、参数还原检查,末尾给 `VERDICT PASS/FAIL` |

## 原理一句话

```
α = (amin + amax)/2 − (amax − amin)/2 · cos(2π(frame − 1 − phs)/dur)
```

与主题 46 的 `amin + (amax − amin)·(0.5 − 0.5·cos θ)` **代数恒等**(展开即知),只是参数写法不同。

## 实测(钟表01,Blender 5.2.2 LTS,-5 / 5 / 100 / 0)

- 帧 1 → **-5.0000**、帧 51 → **+5.0000**、帧 101 → **-5.0000**
- `f` 与 `f+100` 求值最大差 **0.00000000** 度
- 参数改成 12 / 50 / 25 后帧 1 → **12.0000**(与手算一致)
- 8 个网格子对象世界坐标随父级变化

## 注意

- **桥只改内存**,满意了 Ctrl+S
- 驱动表达式**只用内置 `frame` + SINGLE_PROP**,不引自定义 Python 函数
  ⇒ **重开文件驱动不会变红**(无需 Register 文本块)
- 挂驱动前脚本会把**基准角复位为 0**,避免从被污染的基准累加
