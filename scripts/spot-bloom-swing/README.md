# spot-bloom-swing · 射灯阵列「花开 / 花闭合」径向摆动

让一圈射灯各自**锁在自己的竖直径向平面里**摆动 —— 8 盏速度略有差异,起初依次展开,
跑一段后因速度差凑到一处**同时展开**,之后又错开。视觉上就是花开合。

完整原理与坑见 [`docs/射灯阵列径向摆动绽放系统.md`](../../docs/射灯阵列径向摆动绽放系统.md),
作业规范见 [`skills/blender-spot-bloom-swing/`](../../skills/blender-spot-bloom-swing/)。

## 前提

- 已有一圈**定位空对象**(本报告里叫 `射灯`~`射灯.007`,8 个),位置就是要放灯的地方
- 已有**灯对象**(本报告里叫 `射灯_光`~`射灯_光.007`),当前是 plain axes 空物体或已有的灯
- 有一个**中轴线对象**(本报告里叫 `绽放中轴线`),摆动以它为基准
- 走 9877/9888 桥执行(脚本**没有** `if __name__=='__main__'` 守卫,桥端 `__name__` 是 `builtins`)

## 三步走(顺序不能反)

```bash
python send.py -p 9888 probe_bloom.py     # 1. 先看清楚实际几何,别猜
python send.py -p 9888 build_bloom_swing.py   # 2. 建铰链 + 挂驱动
python send.py -p 9888 verify_bloom.py    # 3. 独立核验(必须另一次请求)
```

★ **第 1 步不能省**。定位空对象常常没有旋转(`rotation=(0,0,0)`),**朝向信息是缺失的**,
必须问用户要方向;中轴线对象的高度决定起始线是不是水平的(实测过被抬高 0.855 的情况,
起始线因此变成朝内上方倾斜 18.8°)。

★ **第 2 步和第 3 步必须分两次请求**。同一次 exec 内改完立即验证会读到未刷新缓存值。

## 参数(改完实时生效,不用重跑)

构建后,Blender 里选中 Scene → 属性面板 → 自定义属性:

| 属性 | 默认 | 含义 |
|---|---|---|
| `bloom_period` | 240 | 一次完整开合的帧数 |
| `bloom_sync_frame` | 600 | 8 盏精确同步的帧 |
| `bloom_spread` | 0.10 | 速度差幅度(最快比最慢快 10%) |
| `bloom_min_deg` | 0 | 起始角(0 = 起始线本身) |
| `bloom_max_deg` | 125 | 完全展开角 |

**同步瞬间的展开角由 `sync / period` 的小数部分决定**:
`amax × (0.5 − 0.5·cos(2π·sync/period))`

| sync/period | 同步时的展开角 |
|---|---|
| 2.0(`sync=480`) | 0° —— 整体闭合 |
| 2.25(`sync=540`) | 62.5° —— 半开 |
| 2.5(`sync=600`,默认) | 125° —— 整体全开 |

想让同步发生得更频繁,加大 `bloom_spread`:对齐周期 = `7 × period / spread`
(默认 0.10 ⇒ 16800 帧,3000 帧内只会精确同步一次)。

## 脚本清单

| 脚本 | 作用 |
|---|---|
| `probe_bloom.py` | 探查灯环几何、中轴位置、起始线仰角、现有层级与驱动数;非单位缩放会告警 |
| `build_bloom_swing.py` | 主构建:建铰链 → 灯改挂到铰链 → 挂 SCRIPTED 驱动;幂等(同名铰链复用,旧驱动先删) |
| `verify_bloom.py` | 独立核验:位置误差 / 切向偏离 / 同步帧角差 / 光线到中轴距离,末尾给 PASS-FAIL |
| `undo_bloom.py` | 撤销:灯挂回定位空对象、删铰链、清场景参数(默认恢复成竖直朝上,见 `RESTORE_ROT`) |

## 撤销

```bash
python send.py -p 9888 undo_bloom.py
```

构建前若不是竖直朝上,改脚本顶部的 `RESTORE_ROT` 再跑。

## 实测数据(Blender 5.2.2,8 盏)

- 位置误差 **0**、切向偏离 **0.000000**(8 盏全部锁死在各自径向平面)
- frame 0:展开角 -0.0 / 1.6 / 6.2 / 13.6 / 23.5 / 35.4 / 48.6 / **62.5**(依次错开)
- frame 600:**全部 125.0°,角差 0.000000**
- frame 601:124.98°(开始错开)
- frame 0 灯 0 的光线到中轴距离 **0.0000**(闭合时精确命中花心)

## 注意

- **桥只改内存**,满意了 Ctrl+S
- **移动「绽放中轴线」不会自动重算** —— 起始线的仰角是构建时算出来写死的,
  改完中轴位置需重跑 `build_bloom_swing.py`
- 批量脚本**中途抛异常会留下半改造状态**(实测过:8 盏里只有 1 盏被改成铰链架构,
  朝向跟其余 7 盏不一致)。跑完务必看 `verify_bloom.py` 的 VERDICT
