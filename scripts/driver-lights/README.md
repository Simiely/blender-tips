# driver-lights —— 运动网格灯光方案

给「带驱动上下浮动」的网格对象，在每个轴心自动加一对 AREA 灯（向下照 + 向上照），
灯跟随网格运动、可手动偏移微调、旋转联动——一套完整的"运动物体打灯"方案。

## 场景

- 主装置/机械臂等物体带 bob 上下浮动驱动，想在每个运动单元上加装饰灯光；
- 要两组灯：一组朝下照、一组朝上照（背靠背）；
- 灯要**跟着网格一起动**（网格浮动，灯跟着浮）；
- 偶尔想微调某盏灯的位置/角度，但不想让它脱离跟随。

## 用法

```bash
python send.py build_light_system.py    # 或 Scripting 工作区 Run Script
```

改脚本顶部 `TARGETS`（集合列表），脚本自动：

1. 找集合内所有带 `location.z` 驱动的 MESH
2. 每个网格轴心建 2 盏 AREA 灯（向下 rot=0 / 向上 rot=π）
3. 建「`集合名_灯向下/向上_轴心`」空对象（集合中心），灯 parent 到轴心打组
4. 灯挂位置驱动跟随网格；向上灯 z 额外 +0.001
5. 每盏灯加 `偏移X/Y/Z` 属性（手动微调，不被驱动覆盖）
6. 旋转绑定：向上灯为主（自由转），向下灯跟随（差 π）

## 参数表

| 常量 | 默认 | 含义 |
|---|---|---|
| `TARGETS` | 主装置01~05 | 要处理的集合列表 |
| `LIGHT_SIZE` | 1.0 | AREA 灯尺寸 |
| `LIGHT_SCALE` | 0.26 | 灯对象缩放（=默认灯的 0.26） |
| `DOWN_ENERGY` | 15 | 向下灯亮度（基准 10 × 1.5） |
| `UP_ENERGY` | 20 | 向上灯亮度（基准 10 × 2） |
| `UP_OFFSET_Z` | 0.001 | 向上灯相对网格的 Z 偏移 |
| `OFFSET_PROPS` | 偏移X/Y/Z | 每盏灯的手动偏移属性 |

## 手动微调

- **位置偏移**：选灯 → 属性面板改 `偏移X/Y/Z`（或打关键帧）→ 灯在跟随基础上偏移，运动不丢
- **旋转**：直接转向**向上灯**（主灯），向下灯自动跟随；向上灯本身无旋转驱动，可自由转
- **亮度**：直接改灯 Energy

## 幂等与安全

- **幂等**：已有灯/驱动复用，重跑不重复建、不破坏已有微调（偏移属性保留当前值？——注意：脚本会重置偏移为 0，见下）
- **非破坏**：只动集合内的灯和轴心空对象，网格/其他对象不受影响

## 注意（实战踩的坑）

- **`matrix_parent_inverse` 必须在 `view_layer.update()` 之后设置**：新建轴心空物体后
  立即读 `matrix_world` 是单位矩阵 → parent inverse 变 identity → 灯世界坐标 = 轴心+网格位置
  （整体偏移翻倍）。脚本已内置 update 再设。
- **5.2 的 `DriverTarget` 无 `array_index` 属性**：SINGLE_PROP 读数组分量要用
  `data_path='location[0]'` 带下标，不是设 array_index。
- **脚本改偏移属性不触发驱动重算**（depsgraph 缓存），但 **UI 手动改/打关键帧正常**。
- **驱动单向**：A 跟随 B 和 B 跟随 A 互指会循环报错，所以设计成"向上灯为主、向下灯跟随"。
- 运行后 **Ctrl+S** 保存。

## 持久化（打开自动生效）

`light_off` 是命名空间函数（驱动表达式里调用它）。让重开文件自动恢复：
1. 把 `light_driver.py`（本目录）内容作为文本块放进 .blend，勾 **Register**（`use_module=True`）
2. 偏好设置开启 **Auto Run Python Scripts**
3. Ctrl+S 保存 → 重启后函数自动注册、驱动自动恢复（实测 843 驱动 INVALID 0）

或用 `scripts/driver-restore/restore_drivers.py` 一键恢复（已含 light_driver.py）。
