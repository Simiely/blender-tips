# 驱动式上下浮动噪声系统(跨项目复用包)

给一组独立网格物体加**丝滑有阻尼感的上下浮动**驱动:每个物体围绕自己原位置平滑上下漂,
分层为「全局大波(整体趋势)+ 局部错动(各自错开)」,全部参数做成滑块实时调,可一键换花样。

适用: 点位模型 / 阵列装置 / 任何「想让一堆物体有机地上下浮动、又能统一控制」的场景。

## 文件清单

| 文件 | 作用 | 运行位置 |
|---|---|---|
| `bob_driver.py` | **核心噪波函数** `bob()`:两层加权混合 Perlin 噪波 → 平滑位移,注册进驱动命名空间;勾选 Register 可随 .blend 打开自动恢复 | **Blender 内部**(Scripting 工作区运行) |
| `build_bob_drivers.py` | **通用构建器**:给指定集合的网格挂 Z 驱动、建控制面板、排除不动区;可重复运行(幂等) | 外部,配合桥 `send.py` 或直接 Run Script |
| `../docs/驱动式上下浮动噪声系统.md` | 完整原理 / 参数说明 / 踩坑 | 阅读 |

## 运动原理(一句话)

每个物体的 Z 位移 = 一个**随时间平滑滑动的连续信号 `c`**(在 −1~1 间来回) × 上下限。
`c` 由「全局大波 + 局部错动」加权混合得到,所以天然连续、无突变 → 视觉上的丝滑 + 阻尼感
(噪波过 0 点变化最快、到顶点最慢,形成缓入缓出惯性)。

## 环境要求

- Blender 5.2(实测);桥远程执行见 `scripts/blender-remote-control/`
- `bob()` 依赖 `mathutils.noise`(驱动命名空间内置 `noise` 模块,可用)

## 使用步骤

### 1. 注册 bob 函数(每台机器 / 每次重启 Blender 跑一次)

Blender → Scripting → 文本编辑器 **Open** `bob_driver.py` → **Run Script**(Alt+P)。
可勾 **Register**(文本编辑器右上角)让下次打开 .blend 自动运行。

> ⚠️ `bob()` **不随 .blend 文件保存**。若打开文件后驱动变红,跑一次 `bob_driver.py` 即可。
> 勾了 Register + 开启「偏好设置 → 自动运行 Python 脚本」可免手动。

### 2. 构建驱动(指定你的集合)

编辑 `build_bob_drivers.py` 顶部的 `TARGETS` 列表(默认已是 `主装置01~05` 实战示例):
```python
TARGETS = [
    ('主装置01', '运动控制01', '不修改'),
    # (集合名, 控制面板名, 不动区名包含)
]
```
然后通过桥运行(或直接在 Scripting 工作区 Run Script):
```bash
python send.py build_bob_drivers.py
```

- 每个集合会新建一个**控制面板空物体**(如 `运动控制01`),承载 9 个中文滑块
- 集合内名字含「不修改」的 EMPTY 子树**自动排除**(不动区)
- **可重复运行**:已有驱动的物体跳过,不会重置基准位置 / 种子

### 3. 调参(实时)

选中某个 `运动控制0X` 空物体 → 右侧属性面板(橙色方块)→ 底部 **自定义属性**,9 个滑块:

| 滑块 | 作用 | 默认 |
|---|---|---|
| 最大上移 / 最大下移 | 上下位移距离(可不对称) | 1.0 / 1.0 |
| 移动速度 | 整体快慢 | 1.0 |
| 速度随机范围 | 每个物体速度的随机增减(±) | 0.2 |
| 种子偏移 | 换整套错动花样(改它就重排) | 0.5 |
| 全局大波权重 | 整体趋势占比 | 0.5 |
| 局部错动权重 | 各自错动占比 | 0.2 |
| 全局频率 | 大波频率(低=慢而整) | 0.03 |
| 局部频率 | 错动频率(高=更碎) | 0.02 |

拖时间轴 / `Alt+A` 播放即可看效果。

## 注意事项(踩过的坑)

1. **驱动变量类型无 `SELF`(Blender 5.x)**:旧教程的 `vf.type='SELF'` 报错,改 `d.use_self=True`,表达式里就能用 `self`。
2. **自定义属性显示名 = 键名**:想中文 UI 就直接把键设成中文(`obj['最大上移']=...`),没有 "update(name=)" 这种改显示名的 API。
3. **改名控制物体 / 替换 bob 函数后,旧驱动会"陈旧"**:depsgraph 不自动重算,求值直接返回基准值(看似不动)。给每个 Z 驱动调一次 `driver.update()` 刷新即可(不动 seed/基准)。
4. **`bob()` 不随文件保存**:必须靠文本块 `bob_driver.py` + Register 持久化,否则下次打开驱动变红。
5. **基准位置 `bob_base_z`**:每个物体记录原始 Z,只在它附近振荡,不会跳到原点;构建时只在首次记录。
6. 桥只改内存,**记得 Ctrl+S**。

## 调试建议

- 想换一种「乱法」→ 改 `种子偏移`
- 想更齐步 / 更散 → 调 `全局大波权重` ↑ 或 `局部错动权重` ↓(反之亦然)
- 想更丝滑 → 调低频率 / 速度;想更活泼 → 调高
