# radial-inward-pulse —— 径向「内收多脉冲」发光材质（环数恒定的约束解算）

给「**共心的多个平面 / 球面**」做一套可复用的发光材质：若干个同心亮环
**持续从外往内收**、无缝循环、黑边很细，环数**恒定**（不是"最多"）。

配套文档：[`../../docs/径向内收多脉冲材质.md`](../../docs/径向内收多脉冲材质.md)
（推导与全部坑）；给 AI 的作业规范：[`../../skills/blender-inward-pulse-material/`](../../skills/blender-inward-pulse-material/)

## 场景

三块**两两正交且共心**的平面（XY / XZ / YZ），要在一个共享圆心周围看到 3 个同心亮环
从外往内收、循环、黑边约 10%、且发光限制在一个圆内（四角不要多出环）。

同族的「从中心向外扩散 / 四段循环脉冲」见 [`../blender-radial-pulse-material/`](../../skills/blender-radial-pulse-material/)
—— 那条路是**径向距离场 + 时间链**，这条是**径向距离场 + 周期环带 + 相位推进**。

## 用法

```bash
# 0) 先只读量一遍目标几何（拿圆心、半宽、角点半径）
python send.py probe_target_size.py

# 1) 构建（幂等，可反复跑；每次都重新实测并重算间距）
python send.py build_inward_pulse.py

# 2) 另起一次请求独立核验
python send.py verify_inward_pulse.py
```

三个脚本都是**经桥执行**的：桥运行中（Blender Scripting 工作区跑 `blender_bridge.py`），
用 `python send.py <脚本>` 发送，见 [`../blender-remote-control/`](../blender-remote-control/)。

> ⚠️ 桥 `exec` 环境里 **`__file__` 不存在**，所以脚本内**所有路径/附件都写绝对常量或内联**，
> 不要 `os.path.dirname(__file__)`。
> ⚠️ 送桥的脚本**绝不能带 BOM**（会 `SyntaxError: invalid non-printable character U+FEFF`）。

## 构建脚本顶部配置区

| 常量 | 说明 |
|---|---|
| `COL_NAME` / `PLANES` | 目标集合与网格名 |
| `CTRL_NAME` / `MAT_NAME` | 新建的控制器空物体与材质 |
| `MAT_OLD` / `CTRL_OLD` | **只读**的姊妹材质/控制器：取圆心坐标 + 取配色 ColorRamp |
| `MAX_BANDS` | 目标环数 **N** |
| `REF_FOR_COUNT` | `'CIRCLE'` = 内切圆（**用户说的"看圆"**）／`'CORNER'` = 角点。**§环数约束的基准** |
| `DUTY` / `EDGE_FRAC` | 占空比 / 单侧软边占比 ⇒ 决定**黑边粗细** |
| `FILTER_FRAC` / `MARGIN` | 最小可见宽度（占周期）/ 余量 —— 环数恒定必需的两项 |
| `GLOW_FADE_FRAC` | 亮面裁切的淡出宽度 = 间距 × 该比例 |

姊妹材质的 `Control` 空物体**只读不写**，原材质节点树一个不动。

## 环数是怎么算出来的（核心）

```
可见带窗口 = L + 占空比 − 软边占比 − 2 × 最小可见宽度        必须 ≈ N
    L = R_ref / 脉冲间距
⇒ L = N − 余量 − 占空比 + 软边占比 + 2 × 最小可见宽度
```

**三项都不能少**（每一项都是被实测打回来的）：

| 只写了什么 | 实测症状 |
|---|---|
| `L + 占空比 ≤ N` | 最多出现 **N+1** 条 |
| 再补「− 软边」，没扣 `2×最小可见宽度` | 仍有 **2%** 的相位只显示 **N−1** 条 |
| 全扣干净 | **N 条占比 99.83%**，永不出现 N+1 |

**★ 基准半径必须问清**：正方形板上「内切圆 2.0146」与「角点 2.8491」相差 **√2 倍**
⇒ 按角点定 N 条，圆上只剩 N−1 条。**先问"在哪条半径上数"再算间距。**

构建脚本带**解析扫描**自检：400~600 个相位 × 4000~6000 个半径采样，
同时报告**内切圆**与**角点**两处的环数分布（最小 / 最大 / 恰为 N 的占比）。

## 黑边粗细（和"亮面面积"是两回事）

```
黑边（感知） = 纯黑 (1 − 占空比) + 两侧软边 2 × 软边占比
```

| 目标 | 改哪个 |
|---|---|
| 黑边更细 | 调大 `DUTY`（占空比）；配合调小 `EDGE_FRAC` |
| 想收紧**发光范围**（亮面面积变小） | 改**亮面裁切**（`亮面半径` / `淡出宽度`），**不是**加宽黑边 |

> ⚠️ 把「缩小亮面面积」理解成「加宽黑边」会得到反效果（实测：占空比 0.88→0.60
> 让黑边从 24% 涨到 52%，用户反馈"黑边太粗了"）。两者是**正交**的。

## 关键点（本路实测）

- **驱动只能挂在 `Value` 节点输出上**。挂在 `Math`/`MapRange` 这类**计算节点**的输出插槽 =
  被节点自身运算覆盖 = **等于没写** ⇒ 相位恒 0 ⇒ 拖时间轴**画面完全静止**。
  构建与核验都内置了这条守卫（逐个驱动检查 `data_path` 的目标节点 `type == 'VALUE'`）。
- **时间参数用「循环周期（帧/圈）」而不是「速度（圈/帧）」**：`循环周期 = 1 ÷ 每帧推进的周期数`，
  实现是 `帧号 ÷ 循环周期`。用户填帧数直接（帧数越小转得越快），负值 = 向外扩。
- **配色从姊妹材质读 ColorRamp 色标**（不能读 `Emission Color.default_value` —— 插槽若已连线，
  那只是个残留存值）。构建时**实时读**，以后旧材质改色重跑即同步。
- **色标要按 `r / 色相半径` 归一化**再喂：旧材质色标铺在 `r ∈ [0,1]`（那时网格半宽正好 1.0），
  新网格半宽不同时不归一化，超过 1 的部分全被钳到最后一个色标 ⇒ 整面糊成暗红。
- **核验别读中间节点真值**：已连线的「计算输出」插槽 Python 读回恒为 0
  （只有被关键帧/驱动器**直接写入**的插槽才有可读值）。改成「验基准 + 验驱动输入 + 解析式复算」。

## 文件

| 文件 | 说明 |
|---|---|
| `probe_target_size.py` | 【只读】量目标网格：中心、span、半宽、角点半径、到圆心的 r 分布、现有材质/槽位 |
| `build_inward_pulse.py` | **主建脚本**：控制器 + 材质（径向场 / 周期环带 / 梯形剖面 / 亮面裁切 / 配色复用）+ 驱动；含连线自检与解析扫描 |
| `verify_inward_pulse.py` | **独立核验**（另起请求）：结构 + 驱动 + 配色跨材质对拍 + 裁切链 + 环数独立复算 |
| `copy_to_position.py` | **位置副本**：把当前槽里的材质各复制一份，圆心搬到网格新位置（自动编号 `_位N`、防叠名） |
| `make_effect_independent.py` | **快照式独立化**：把一组空对象名下共享的网格数据逐对象独立（先快照后动手） |
| `diag_sharing.py` | **三层共享诊断**：网格数据 / 材质 / 控制器 哪一层在共享、被谁共用 |

## 多位置部署与播放时差

同一套径向材质要部署到多个位置、并让各处播放**错开一段时间** —— 完整做法与坑见
[`../../docs/径向材质多位置部署与时差.md`](../../docs/径向材质多位置部署与时差.md)。要点：

- **位置副本**：`copy_to_position.py`（动态定位 + 自动编号 `_位N` + 防叠名）。
  ⚠ 带关键帧的材质复制后 **action 会与原件共用**，`action.copy()+重绑 slot` 实测无效
  （评估值冻结）⇒ 必须 `ad.action=None` 再原地 `keyframe_insert` 重建
- **三层共享**：「改一个其它跟着变」= ①共享网格数据 ②共享材质 ③共享控制器（三者正交）。
  `diag_sharing.py` 一把探出来；`make_effect_independent.py` 做**快照式独立化**
  （⚠ 不能一边遍历一边判 `users>1` —— 复制一个 users 就掉，兄弟对象会被跳过，实测漏 28 个）
- **播放时差**：时间错位 ≡ 相位偏移（`相位偏移 = 错位帧数 ÷ 循环周期`，内收类零改动、取 mod 1）；
  四段循环类改 TVAL 两个关键帧的【值】（`值 = 帧 + 错位`，斜率不变）。
  ⚠ 相位偏移存的是圈数不是帧数 —— 改循环周期，等效帧错位会跟着变

## 注意

- 姊妹材质（`MAT_OLD`）与它的控制器**全程只读**，核验里对拍了 `users` / 节点数 / 驱动数 / 色标逐项一致。
- 非圆网格上环数**天然不均匀**（角点比内切圆多），这是几何决定的，交付时**要主动说明**。
