# Blender 参数化弹出门与角色控制

传输层见 `blender-bridge-ops` skill。本 skill 只讲“门 + 角色弹出”的参数化改造。

## 铁律（顺序不可颠倒）

1. **先只读抓基线**：记录当前 local/world 位姿，禁止凭文字描述猜起点
2. **让用户确认哪一端是初始、哪一端是最终**
3. **一个控制器管所有方向**：不要为第二组另建控制器
4. **弧度常量直接进表达式**：不要套 `radians()`
5. **角色只改单一轴**：通常是 Y，X/Z 保持基线
6. **独立核验**：另起请求检查端点、单调方向、子对象随动
7. **提醒用户 Ctrl+S**

## 一、作业流程

| 步骤 | 脚本 | 说明 |
|---|---|---|
| 1 | `probe_current_pose.py` | 只读探当前状态，防止用户已改场景 |
| 2 | `capture_3oclock.py` | 抓第一组基线 JSON/TXT |
| 3 | `build_3oclock.py` | 建控制器 + 3 条驱动 |
| 4 | `fix_radians_expr.py` | 修复误套 `radians()` 的门表达式 |
| 5 | `verify_3oclock.py` | 第一组独立核验 |
| 6 | `capture_10oclock.py` | 抓第二组当前状态 |
| 7 | `build_10oclock.py` | 复用同一控制器挂 3 条驱动 |
| 8 | `verify_10oclock.py` | 第二组独立核验，注意角色 Y 递减 |

## 二、对象与参数

控制器：`3点钟_弹出控制["弹出进度"]`，范围 `0–10`。

用户最终把关键帧调整为 `(30,0) → (75,10)`。

端点见 `../docs/参数化弹出门与角色控制系统.md` 第四节。

## 三、安全闸

| 闸 | 内容 |
|---|---|
| 基线闸 | 执行前必须有 JSON/TXT 基线 |
| 状态闸 | 初始/最终方向必须由用户确认 |
| 弧度闸 | 表达式中的常量是 rad，不再 `radians()` |
| 单轴闸 | 角色只改 Y，X/Z 逐位比对 |
| 复用闸 | 第二组必须指向同一个控制器属性 |
| 核验闸 | 6 条驱动全部 `is_valid=True` |

## 四、绝对不能干的事

- 不要根据“现在门是最终状态”这类一句话直接改，必须重新抓数据
- 不要把控制空物体当成无用 EMPTY 清理掉
- 不要用递增判据核验递减的角色 Y
- 不要在 Blender 5.x 里假设 `action.fcurves` 还能直接用
- 不要驱动角色 X/Z

## 五、核验判据

- `弹出进度` 存在且范围 0–10
- 6 条驱动 `is_valid=True`
- 3点钟右门 rotZ：`3.141592741 → 0.968994`
- 3点钟左门 rotZ：`0 → 2.207841`
- 3点钟角色 Y：`-8.837891 → -343.205627`
- 10点钟右门 rotZ：`0 → -2.775074`
- 10点钟左门 rotZ：`0 → 2.722714`
- 10点钟角色 Y：`31.439859 → 31.018097`，递减
- 子对象随父级移动
- 用户已提醒 Ctrl+S
