# Blender 几何节点泡泡发射系统

传输层见 `blender-bridge-ops` skill。本 skill 只讲“泡泡发射”这一件事的方法论与脚本。

## 铁律（顺序不可颠倒）

1. **只读探场景**：确认 `发射口` 是 EMPTY、`泡泡范围` 是水平面，记录中心/半径/包围盒
2. **只读探 GN API**：用 `../scripts/geometry-node-bubble-emitter/probe_gn_api.py` 落盘 socket 名，不猜 API
3. **给控制器参数**：中文键名 + 硬 `min/max`，驱动节点内 `Value`，不驱动修改器 socket
4. **先建基础系统，再按顺序打补丁**：不要一上来写全量复杂节点组
5. **每阶段另起请求独立核验**：重新取引用，不能复用执行脚本内存状态
6. **提醒用户 Ctrl+S**：桥只改内存

## 一、判断该不该用本 skill

适用：

- 需要从空对象发射球体/泡泡
- 需要贴合某个网格的 XY 圆形范围
- 需要循环生命周期、随机相位、先上后下
- 需要出生门控、淡出、随机消散、整体倍率

不适用：

- 只需要礼花式短暂喷射 → 用 `粒子系统礼花喷射方案`
- 只需要雪花式均匀下落 → 用 `雪花下落系统`
- 只是星芒/亮片散布 → 用 `星芒散射光效系统`

## 二、作业流程

| 步骤 | 脚本 | 产出 |
|---|---|---|
| 1 | `probe_state.py` | 当前控制器参数与节点状态 |
| 2 | `probe_gn_api.py` | Blender 5.3 GN socket/operation 清单 |
| 3 | `build_bubble_emitter.py` | 基础系统：Mesh Line + Set Position + Instance on Points |
| 4 | `patch_01_range_match.py` | 范围圆心/半径匹配 |
| 5 | `patch_02_fade_kill.py` | 出生淡入、死亡淡出、下落随机消散 |
| 6 | `patch_03_slow_all.py` | 整体降低生成密度与速度 |
| 7 | `patch_04_speed_multiplier.py` | 把速度变成可驱动倍率 |
| 8 | `patch_optional_apex_ratio.py` | 可选：独立调顶点比例 |
| 9 | `verify_bubble_emitter.py` | 独立核验 |

## 三、对象与关键参数

对象必须在 `泡泡系统` 集合：

- `泡泡控制`：EMPTY，中文滑块
- `泡泡_源球`：MESH，隐藏渲染与视口，带半透明材质
- `泡泡发射_系统`：MESH + NODES 修改器

关键参数见 `../docs/几何节点泡泡发射系统.md` 第四节。

## 四、安全闸

| 闸 | 内容 |
|---|---|
| 原对象保护 | 不修改 `发射口` / `泡泡范围` 本体变换 |
| 源球保护 | `hide_render=True` 且 `hide_set(True)` |
| 边界保护 | 以范围圆心/半径做目标分布，保留径向钳制兜底 |
| 时间保护 | `FLOORED_MODULO` + 出生帧门控，出生前无实例 |
| 落地保护 | 两端淡隐缩放，禁止满尺寸地面突跳 |
| 核验保护 | 另起请求，检查越界、地面突跳、驱动、参数 |

## 五、绝对不能干的事

- 不要给 `发射口` 直接加修改器；它只是锚点
- 不要用普通 `MODULO` 处理负时间
- 不要把 `radians()` 用在已经是弧度的值上（这是弹出门 skill 的坑，但同类错误）
- 不要在同一脚本改完自定义属性后不 `update_tag()` 就读驱动结果
- 不要把源球显示出来，也不要删除 `泡泡范围`
- 不要在桥里执行文件级 operator（`read_factory_settings` / `read_homefile` / `wm.open_mainfile`）

## 六、核验判据

- 起始帧前实例数为 0（当起始帧大于 0 时）
- 改 `慢速倍率` 后同帧数量变化，并恢复
- 所有实例 XY 投影不越出 `泡泡范围`
- 近地没有满尺寸实例
- `下落消散=0` 时实例数等于 `泡泡数量`
- `发射口` / `泡泡范围` 未移动
- 输出报告落盘，用户提醒 Ctrl+S
