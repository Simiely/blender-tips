# 空物体父级整体挪动集合(总控 Empty)

> 适用: Blender 5.2 LTS(机制对所有版本通用)
> 依据: 官方手册 Parenting / Object Parent 章节(2026-09-30 核对)

## 场景

一个集合里堆了几十个对象,各自带关键帧动画。需求:**把整个集合挪个位置**(或转个角度),
但不能逐个重 K 动画——每个对象自己的动画要原样继续播。

**目标**: 新建一个空物体当"总控",以后只动它,整个集合整体偏移;对象自己的动画一帧都不受影响。

## 原理: 三段矩阵链

```
child.matrix_world = parent.matrix_world @ child.matrix_parent_inverse @ child.matrix_basis
```

| 段 | 是什么 | 谁在写 |
|---|---|---|
| `parent.matrix_world` | Empty 的变换 | 你手动移/转/缩 Empty |
| `matrix_parent_inverse` | **挂父级那一刻的补偿快照** | Ctrl+P 自动算一次,之后不再变 |
| `matrix_basis` | 对象自身 loc/rot/scale | **关键帧动画全在这段** |

三条关键推论:

1. 挂父级时 Blender 当场算 `matrix_parent_inverse` = 「当时 Empty 世界变换的逆矩阵」,
   把 Empty 当前位置从继承链里抵消掉 → **挂完所有对象原地不动,一个都不跳**。
2. 这个矩阵只算一次,之后 Empty 怎么动就怎么原样下传 → 「动 Empty = 整体偏移」的机制基础。
3. 关键帧只写在第三段(`matrix_basis`),父级叠加在动画**之外** → 动画播放完全不受影响。

## 做法

1. `Shift + A` → **Empty → Plain Axes**,建总控空物体(建议放在集合视觉中心附近,
   否则后面旋转/缩放是绕着远处的原点转,手感极差)
2. 大纲视图右键集合 → **Select Objects**(选中集合内全部对象)
3. 按住 `Shift` 点选空物体,让它成为**活动对象**(最后选中的高亮那个)
4. `Ctrl + P` → **Object (Keep Transform)**
5. 之后只移动/旋转/缩放这个空物体,整个集合整体偏移

集合内对象本来就独立(互无父子)时,选 **Object** 效果完全一样;
`Keep Transform` 的差别只在「对象已有旧父级」时才体现(见下表)。

## Ctrl+P 三个 Object 选项到底差在哪(官方手册核对)

| 选项 | 行为 | 适用 |
|---|---|---|
| Object | 已有旧父级先解除(对象回到自身变换,**丢掉旧父级的影响**),再算 inverse 保持世界位置 | 集合内无内部父子时的标准选法 |
| Object (Keep Transform) | 计算当前世界变换(**含旧父级带来的影响**),挂新父级后仍停在世界原位 | 对象已在别的层级里,换父级时不想跳 |
| Object (Without Inverse) | 挂父级并重置 inverse,对象**跳到父级位置**(保留旋转缩放) | CAD 类,父子坐标对齐场景 |

## 为什么必须「只挂顶层对象」

每个对象**只能有一个父级**,`Ctrl+P` 会**先解除旧父级再挂新的**。假设集合里 A 是 B 的父级
(A 是车身、B 是门),全选(含 B)后直接挂 Empty:

- **层级被拍平**: A→B 被解除,B 直接挂到 Empty;之后 A 的动画带动不了 B,动画语义全变。
- **位置会跳**: 解除旧父级时 B 回到自身变换,丢掉从 A 继承的偏移(官方手册明确写了此行为)。

只挂顶层(A 和 C): 继承链 `Empty → A → B` 一路唯一,Empty 动,全体跟着动,无双重变换。

## 坑(官方手册确认/实测)

### 1. 属性面板填 Parent 会跳位置
属性面板(Object Properties → Relations)手动填 Parent 槽位时,`matrix_parent_inverse` **被强制重置**,
对象跳进父级坐标系。挂父级一律走 `Ctrl+P`(或大纲视图拖拽,同为 Keep Transform 语义,保持世界位置)。

### 2. `Ctrl+Shift+P`(Clear Parent Inverse)别乱按
它把补偿矩阵清空 → 对象瞬间跳进 Empty 的坐标系。排查"对象为什么飞了"时最先查这个误触。

### 3. 缩放 Empty 谨慎: 非均匀缩放 + 子级旋转 = 剪切
官方已知限制: 父级非均匀缩放且与子级有相对旋转 → **shear(剪切)变形**,
且解除父级时剪切无法还原(loc/rot/scale 表示不了剪切)。移动随便,旋转可以,缩放尽量均匀或不缩。

### 4. 反悔与还原(`Alt+P`)
- **Clear and Keep Transformation**: 带着当前位置脱离父级(最常用)
- **Clear Parent**: 回到挂父级前的原始变换
- **Clear Parent Inverse**: 不解除父子,只清补偿矩阵(= 对象跳进父级坐标系,慎用)

## 与集合实例化的对比

| | 空物体父级(本文) | 集合实例化(Shift+A → Collection Instance) |
|---|---|---|
| 原对象 | 真正重新挂载,原地不动 | 完全不碰 |
| 移动方式 | 动 Empty,原集合整体偏移 | 动实例物体,原件留在原地 |
| 继续编辑 | 直接编辑原对象 | 双击实例进入(或关 instancing) |
| 适合 | 这堆东西要**永久挪位置** | 同一堆东西要**复制/引用多份** |
