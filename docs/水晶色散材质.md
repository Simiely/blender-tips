# 水晶色散材质（四玻璃加色 + 光程深度切换 + 噪波控粗糙度）

> 来源：https://www.youtube.com/watch?v=RMXZJw7Fu9g 《Dispersion glass material in Blender》（教程复刻 + 5.2 实测校正）
> 适用：Blender 5.2 LTS，Cycles（`Light Path` / `Add Shader` 语义在 EEVEE 下不同，未验证）
> 关键词：色散、Dispersion、Glass BSDF、Add Shader、Light Path / Transmission Depth、Mix Shader、ColorRamp 三段、噪波控粗糙度

---

## 零、一句话

**四片 Glass（红/绿/蓝/白）用 `Add Shader` 相加**，再用 `Light Path.Transmission Depth` 当 `Mix Shader` 的系数：
**表面（深度 0）走彩色三片的加色叠加，光线进入内部（深度 ≥1）切到纯白一片**，避免内反射被反复染色而发浑。
三片彩色玻璃的**粗糙度**由「噪波 → 三段 ColorRamp」控制 ——
**色带必须是三段（`0.000` 黑 / `0.459` 黑 / `1.000` 白）**，写成两段（`0` 黑 → `0.459` 白）会把半个表面糊成磨砂白。

---

## 一、场景

想要**通透水晶 + 边缘细密彩虹彩边**（真实钻石那种火彩），但：

- Blender 5.2 **没有任何原生色散参数**（`Principled` 32 个插槽、`Glass BSDF` 7 个插槽逐个枚举过，都不含 Dispersion；`scene.cycles` 也没有光谱开关）
- 三片纯 RGB 玻璃直接相加时，**颜色分离集中在轮廓**，且本体容易发暗或被内反射染浑
- 希望表面**大部分保持通透**，只有局部（噪波峰值处）是磨砂的，形成"干净玻璃 + 局部彩斑"

---

## 二、总体架构

```
纹理坐标.Object
  └─ 映射(恒等, Scale 1,1,1)
      └─ 噪波纹理(Scale 15, Detail 15, Roughness 1, Lacunarity 2)
          └─ 颜色渐变(三段: 0.000 黑 / 0.459 黑 / 1.000 白)
              ├─ 玻璃 BSDF    (红, IOR 1.450).Roughness
              ├─ 玻璃 BSDF.001(绿, IOR 1.500).Roughness
              └─ 玻璃 BSDF.002(蓝, IOR 1.550).Roughness

相加着色器   ← 绿 + 蓝
相加着色器.001 ← (上一步) + 红
混合着色器.Fac ← 光程.Transmission Depth
混合着色器.Shader1 ← 相加着色器.001   （表面：彩色叠加）
混合着色器.Shader2 ← 玻璃 BSDF.003    （内部：纯白, IOR 1.500, Roughness 0, 不接色带）
→ 材质输出.Surface
```

**为什么这样分工**：`Add Shader` 是**能量相加**，四片叠加会比单片亮一倍；靠 `Transmission Depth`
把"表面那一次"和"内部多次"分开，是让彩色只作用在首次折射上、内部保持中性的关键。

---

## 三、节点清单（实测 13 节点 / 14 连线）

| 节点 | 类型 | 关键值 |
|---|---|---|
| 纹理坐标 | `TEX_COORD` | 只用 `Object` 输出 |
| 映射 | `MAPPING` | Type=Point，**Scale (1,1,1) 恒等** |
| 噪波纹理 | `TEX_NOISE` | 3D，Scale **15**，Detail **15**，Roughness **1**，Lacunarity **2**，Distortion 0 |
| 颜色渐变 | `VALTORGB` | RGB / Linear，三段：`0.000 黑` → `0.459 黑` → `1.000 白` |
| 玻璃 BSDF | `BSDF_GLASS` | 红 (1,0,0)，IOR **1.450**，Roughness ← 色带 |
| 玻璃 BSDF.001 | `BSDF_GLASS` | 绿 (0,1,0)，IOR **1.500**，Roughness ← 色带 |
| 玻璃 BSDF.002 | `BSDF_GLASS` | 蓝 (0,0,1)，IOR **1.550**，Roughness ← 色带 |
| 玻璃 BSDF.003 | `BSDF_GLASS` | 白 (1,1,1)，IOR **1.500**，Roughness **0**（不接色带） |
| 相加着色器 ×2 | `ADD_SHADER` | 绿+蓝 → 再 +红 |
| 光程 | `LIGHT_PATH` | 只用 `Transmission Depth` |
| 混合着色器 | `MIX_SHADER` | Fac ← Transmission Depth |
| 材质输出 | `OUTPUT_MATERIAL` | — |

## 四、接线表（逐条）

```
纹理坐标[Object]            → 映射[Vector]
映射[Vector]                → 噪波纹理[Vector]
噪波纹理[Factor]            → 颜色渐变[Factor]
颜色渐变[Color]             → 玻璃BSDF[Roughness]
颜色渐变[Color]             → 玻璃BSDF.001[Roughness]
颜色渐变[Color]             → 玻璃BSDF.002[Roughness]
玻璃BSDF.001[BSDF]          → 相加着色器[Shader]
玻璃BSDF.002[BSDF]          → 相加着色器[Shader]
相加着色器[Shader]          → 相加着色器.001[Shader]
玻璃BSDF[BSDF]              → 相加着色器.001[Shader]
光程[Transmission Depth]    → 混合着色器[Factor]
相加着色器.001[Shader]      → 混合着色器[Shader]
玻璃BSDF.003[BSDF]          → 混合着色器[Shader]
混合着色器[Shader]          → 材质输出[Surface]
```

## 五、实测数据（同宝石 / 同棚拍布光 / 700 samples / 差分掩膜统计）

| 材质 | 彩色面积 | 色相数 | 亮度 | 平均饱和 | 观感 |
|---|---|---|---|---|---|
| **本主题（三段色带）** | 37.1% | 3 | 0.49 | 0.22 | 通透水晶 + 边缘细密彩边，最像真实钻石火彩 |
| 同上但写成**两段**色带 | 0.0% | 2 | 0.85 | 0.02 | ❌ 整颗磨砂白 |
| 同上但**不加光程切换** | 0.0% | 1 | 0.90 | 0.01 | ❌ 四片叠加过曝成白 |
| 对照：三玻璃 + 520nm 薄膜 | 61.1% | 5 | 0.39 | 0.37 | 彩边更宽更艳，但略"甜" |

统计口径：先用**同机位空背景板做差分掩膜**，只统计水晶覆盖的像素，再算色相分布 ——
不做掩膜直接全图统计会把背景渐变算进去（实测 96% 像素被误判为"彩色"）。

## 六、坑（按严重度）

### ★★★ 色带必须是三段，不是两段

写成 `0.000 黑 → 0.459 白`（两段）时，噪波值 ≥0.459 全部输出白 = **粗糙度 1**，半个表面被糊死，
渲染出来是**一颗磨砂白瓷**（实测彩色面积 0.0%、亮度 0.85）。

正确写法是**在 0.459 处插一个黑标**：`0.000 黑 → 0.459 黑 → 1.000 白`。
这样 0–0.459 区间恒为黑（粗糙度 0，通透），只有噪波峰值那一小片才磨砂。
**同一个材质，只改这一个色标位置，彩色面积从 0.0% 涨到 37.1%。**

### ★★★ `Transmission Depth` 接 `Mix Shader.Fac`，不是接噪波向量

它是**着色器混合系数**，用来区分"表面首次折射"与"内部多次弹射"。
接到噪波的向量输入上（我最初的理解错误）等于让**内反射深度去扰动粗糙度**，机制完全不同，结果是一团白雾。

### ★★ `Add Shader` 是能量相加，四片 = 两倍亮度

四片 RGBW 叠加不归一化时，实测亮度 **0.90**（严重过曝，颜色全被冲白）。
如果场景本来偏亮，可把四片颜色按 1/2 缩放，或降低灯光功率 —— 但**不要靠调色带**去救曝光。

### ★★ 5.2 的节点改名，老教程照抄会 KeyError

- `Combine HSV` 已并入 `Combine Color`（`mode='HSV'`），`ShaderNodeCombineHSV` 未定义
- `RGB Curves`：`ShaderNodeRGBCurves` 与 `ShaderNodeCurveRGB` **两个名字都不存在**
- `ShaderNodeTexGradient` 的 LINEAR 取的是向量 **X** 分量，做竖向渐变要走 `Separate XYZ → Z`

### ★ 取景前必须 `view_layer.update()`

用脚本移动物体后立刻读 `bound_box` / `matrix_world` 会拿到**陈旧矩阵**，机位会完全跑偏
（实测相机被推到 y=-375，物体只剩半个在画面边缘）。
改完 `location` 先 `bpy.context.view_layer.update()`，再算包围盒。

### ★ 桥只改内存，不存盘

通过 9999 桥改的材质不会自动落盘；要么用户 Ctrl+S，要么另存新文件后再引用。

## 七、核验清单

新建后按这个清单确认，任一条不符就说明接线错了：

1. **节点 13 个、连线 14 根**（`len(nt.nodes)` / `len(nt.links)`）
2. **色带 3 个色标**，位置分别是 `0.000 / 0.459 / 1.000`，前两个颜色为黑
3. **三片彩色玻璃的 Roughness 有连线**，白色那片 Roughness 是常量 `0`
4. **`Light Path.Transmission Depth` 连到 `Mix Shader.Factor`**（不是别的插座）
5. 渲染后统计：彩色面积应 > 30%、亮度在 0.45–0.55 区间；若彩色面积≈0 且亮度 >0.8，就是色带写成两段了

## 八、与其他色散方案的分工

| 方案 | 机制 | 适合 |
|---|---|---|
| **本主题** | 四玻璃加色 + 光程切换 + 噪波粗糙度 | 通透水晶 + 细密彩边，观感最接近真实宝石火彩 |
| 三玻璃 + 520nm 薄膜 | 折射分离 + 表面薄膜干涉 | 彩边更宽、更饱和，适合"夸张一点"的产品图 |
| `Refraction BSDF` + `Glossy` + 白噪波（连续色散） | 逐着色点随机 IOR | **背光水滴 / 棱镜 / 激光**这类强逆光场景；多面宝石上会发闷（无内反射） |

**选择判据**：要"像真宝石"选本主题；要"彩虹更张扬"选三玻璃+薄膜；要拍透射光斑/焦散才用连续色散。
