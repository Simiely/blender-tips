# 天空太阳控制驱动 · Blender 5.2

> 把天空纹理的太阳高度(`sun_elevation`)和太阳角度(`sun_rotation`)接到一个空物体
> 「天空控制」的「太阳高度 / 太阳角度」滑块(度)上,实时驱动天空;打关键帧即可做
> 太阳升降 / 旋转动画。
> **推荐用命名空间函数版**:脚本 / UI 改值都立即生效,一次同时驱动高度 + 旋转;
> 可复用脚本见 `scripts/driver-sky/sky_driver.py`。

## 场景

- 想调天空太阳高度 / 太阳方位,或做太阳升降、旋转动画;
- `sun_elevation` / `sun_rotation` 是弧度,直接打关键帧不直观 → 要「度」的滑块;
- 动画控制集中在一个空物体上,方便管理。

## 原理

1. 天空纹理节点(`TEX_SKY`,类型 `MULTIPLE_SCATTERING` 等)的 `sun_elevation` / `sun_rotation`
   是**节点属性**,单位**弧度**(如 0.0524 rad ≈ 3°)。
2. 建空物体「天空控制」,写自定义属性 `太阳高度`(度) / `太阳角度`(度)。
3. 用**命名空间函数** `sky_sun_angle()` / `sky_sun_elev()` **实时读属性并转弧度**——摆脱
   SINGLE_PROP 缓存坑,脚本 / UI 改值都立刻生效。
4. 给 `sun_rotation` / `sun_elevation` 挂 SCRIPTED 驱动,表达式为对应函数。
5. 对「太阳高度 / 太阳角度」打关键帧(悬停属性按 `I`) → 太阳升降、旋转动画。

- 驱动表达式 `sky_sun_elev()` 引用的是**命名空间函数**;

## 推荐做法:命名空间函数版(5.2 实测)

> 数字驱动版(SINGLE_PROP 直接指属性)存在已知坑:**脚本内改滑块值不重算**(depsgraph 缓存,
> 读到 0),只有 **UI 手动改 / 打关键帧正常**。若要脚本改值也立即生效、或一次同时驱动
> **太阳旋转 `sun_rotation`**,用**命名空间函数实时读属性**——与 `light_driver.py` 同模式。

### 做法

1. 建/复用空物体 `天空控制`,加自定义属性:
   - `太阳高度`(度,默认当前高度)→ 驱动 `sun_elevation`
   - `太阳角度`(度,默认当前旋转)→ 驱动 `sun_rotation`
2. 建 Register 文本块 `sky_driver.py`(见 `scripts/driver-sky/sky_driver.py`),注册命名空间函数
   `sky_sun_angle()` / `sky_sun_elev()`(读 `天空控制["太阳角度"/"太阳高度"]`,度 -> 弧度)。
3. 给天空纹理的 `sun_rotation` / `sun_elevation` 挂 SCRIPTED 驱动,表达式
   `sky_sun_angle()` / `sky_sun_elev()`;变量用一个 `SINGLE_PROP` 指向对应自定义属性
   (仅作**依赖触发器**,函数实时读 bpy,故脚本/UI 改值都立即生效)。

```python
# 挂驱动示例(改 nt.animation_data, 路径含节点名)
nt = bpy.data.worlds['World'].node_tree
for path, prop, fn in (('nodes["天空纹理"].sun_rotation', '太阳角度', 'sky_sun_angle'),
                       ('nodes["天空纹理"].sun_elevation', '太阳高度', 'sky_sun_elev')):
    fc = nt.animation_data.drivers.new(path, index=0)     # 先清同名旧驱动
    d = fc.driver; d.type = 'SCRIPTED'
    v = d.variables.new(); v.name = 'a'; v.type = 'SINGLE_PROP'
    t = v.targets[0]; t.id = bpy.data.objects['天空控制']; t.data_path = '["%s"]' % prop
    d.expression = fn + '()'
```

### 坑

- **别再跑旧的 `build_sky_sun_driver.py` 重建**:它会把 `sun_elevation` 驱动写回**常量**
  (如 `.1` = 5.73°)导致高度无反应;统一用 `sky_driver.py` 命名空间版。
- 驱动后 `Ctrl+S`,并保持偏好设置 **Auto Run Python Scripts** 开启(Register 文本块自动恢复)。
- 单位:属性面板输入度,函数内 `math.radians` 转节点需要的弧度。
- 悬挂驱动用 `d.driver.type='SCRIPTED'`;排查/移除遍历 `nt.animation_data.drivers`,匹配
  `data_path` 里含 `sun_elevation` / `sun_rotation` 的条目。

## 旧做法:数字驱动版(不推荐, 有已知坑)

> 与上面推荐版不同,它用 SINGLE_PROP **直接**把「度」属性换算成表达式结果;
> **脚本内改值不重算**(depsgraph 缓存),只 UI 手动改 / 关键帧正常。新场景请用命名空间函数版。

1. 天空纹理节点太阳高度是节点属性 `sun_elevation`,弧度。
2. 建空物体「天空控制」,写自定义属性 `太阳高度`(度,默认 3°,范围 -90~90°)。
3. 给 `sun_elevation` 挂 SCRIPTED 驱动,表达式 `elev * DEG2RAD`,变量 `elev`
   用 SINGLE_PROP 指向 `天空控制["太阳高度"]` → 滑块改值,天空实时跟随。
4. 对「太阳高度」打关键帧(悬停属性按 `I`) → 太阳升降动画。

### 踩过的坑(旧版)

- **5.2 天空纹理的太阳参数是节点属性,不是输入 socket**:`TEX_SKY` 节点 inputs 里只有
  `Vector`,太阳相关参数(`sun_elevation`/`sun_rotation`/`sun_intensity`/`sun_size`)全是
  节点属性,直接 `sky.sun_elevation` 访问;挂驱动用 `sky.driver_add('sun_elevation')`。
- **节点驱动存在 node_tree.animation_data 上,不是节点上**:`ShaderNodeTexSky` 没有
  `animation_data` 属性,驱动实际挂在 `sky.id_data`(节点树)上,路径形如
  `nodes["天空纹理"].sun_elevation`。排查/移除驱动要遍历 `nt.animation_data.drivers`。
- **脚本内改滑块值不触发驱动重算**(depsgraph 缓存,SINGLE_PROP 读自定义属性的已知现象);
  但**用户 UI 手动改 / 打关键帧完全正常**。验证逻辑用"打关键帧 + 跨帧读值",别用"脚本改值再读"。
- 桥接 exec 时 `__name__` 是 `builtins`,脚本直接调 `main()`,不用 `__main__` 守卫。
- 运行后 Ctrl+S,控制面板与驱动才落盘。
