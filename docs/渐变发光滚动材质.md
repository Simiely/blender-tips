# 渐变发光滚动材质 · Blender 5.2

> 把竖图渐变贴图做成**自发光 + 竖直匀速滚动**的材质，滚动速度用空物体滑块驱动。
> 可复用脚本见 `scripts/glow-scroll-material/build_glow_scroll_material.py`。

## 场景

- 物体要一个"灯光渐变 + 流动"的发光效果（如装置上的灯条/灯柱）；
- 渐变方向竖直、与灯光一致（顶亮底暗）；
- 贴图放大只显示一部分 + 匀速滚动 → 灯光流动动画；
- 滚动速度可驱动调节（打关键帧变速）。

## 原理

1. **节点链**：`纹理坐标(UV) → 滚动映射(Mapping) → 渐变贴图(001.png) → 原理化BSDF`
2. **自发光**：贴图颜色同时接 `Base Color` + `Emission Color`，`Emission Strength=1.0`
3. **放大 2 倍只显示一半**：Mapping `Scale Y=0.5` → V 坐标压缩到 0~0.5，
   贴图竖直放大 2 倍、只显示上半（顶亮区）
4. **匀速滚动**：Mapping `Location Y` 挂驱动 `fr * scroll_speed()`，
   `fr` = scene.frame_current（SINGLE_PROP），每帧 +0.05 V → 渐变竖直流动
5. **速度可驱动**：控制空物体「贴图滚动控制」的 `滚动速度` 滑块，
   `scroll_speed()` 命名空间函数实时读它（打关键帧 = 变速动画）

## 做法

```bash
python send.py build_glow_scroll_material.py   # 或 Scripting 工作区 Run Script
```

改 `MAT_NAME` / `IMG_PATH` 后运行，材质重建 + 控制面板自动就绪。

## ⚠️ 坑(实战踩的)

- **Mapping 的 Location/Scale 是 socket**(inputs[1]/inputs[3])，但**有些纹理参数是节点属性**
  （如 `TEX_SKY.sun_elevation`）。先确认目标是 socket 还是属性再挂驱动。
- **节点驱动挂在 node_tree.animation_data**：路径 `nodes["滚动映射"].inputs[1].default_value`，
  `ShaderNodeMapping` 自身无 animation_data（挂/查驱动都找节点树）。
- **脚本改滚动速度不立即生效**（depsgraph 缓存），UI 手动改/打关键帧正常。
  用命名空间函数 `scroll_speed()` 实时读，避免 SINGLE_PROP 缓存自定义属性。
- 桥接 exec `__name__` 是 `builtins`，脚本直接调 `main()`，不用 `__main__` 守卫。

## 调试建议

- 滚动不动 → 检查 Mapping Location Y 驱动是否在 `nt.animation_data` 上；
- 方向反了 → `fr * scroll_speed()` 改 `-fr * scroll_speed()`；
- 想显示下半 → Scale Y 改 -0.5（负缩放翻转显示区域）；
- 变速 → 对「贴图滚动控制.滚动速度」打关键帧。
