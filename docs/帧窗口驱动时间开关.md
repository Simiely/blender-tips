# 帧窗口驱动:按帧区间开/关节点参数(渐变时间开关)

> 场景:一个材质节点参数(如同心圆渐变开关)想在**指定帧区间内生效、区间外关闭**
> (例:0–516 纯色 → 517–657 渐变 → 658+ 纯色),播放时逐帧实时跟紧时间线。
> 做法:命名空间函数 `grad_window(fr)` + SCRIPTED 驱动读 `scene.frame_current`。

---

## 1. 场景与需求

某发光材质有"同心圆渐变"效果,用户希望它**只在动画的某一段出现**:
- 0–516:无渐变,均匀自发光(纯色);
- 517–657:显示渐变同心圆;
- 658 及之后:恢复无渐变。

并希望:
1. 播放/拖动时间线时开关**实时正确**变化;
2. **换电脑 / 重开工程**后效果与开关仍稳定,驱动不报红。

---

## 2. 做法(5.2 可靠的方案)

### 2.1 命名空间函数做帧窗口

把"落在指定闭区间返回 1,否则返回 0"写成一个命名空间函数,放进 driver_namespace:

```python
def grad_window(fr):
    return 1.0 if 517.0 <= fr <= 657.0 else 0.0
bpy.app.driver_namespace['grad_window'] = grad_window
```

### 2.2 挂 SCRIPTED 驱动到目标 Value 节点输出

目标为该材质的 Value 节点(如"主装置_渐变开关")的输出 socket:

```python
sock = m.node_tree.nodes['主装置_渐变开关'].outputs[0]
fc = sock.driver_add('default_value')
d = fc.driver
d.type = 'SCRIPTED'
v = d.variables.new(); v.name = 'fr'; v.type = 'SINGLE_PROP'
v.targets[0].id_type = 'SCENE'
v.targets[0].id = bpy.context.scene
v.targets[0].data_path = 'frame_current'   # 依赖场景当前帧
d.expression = 'grad_window(fr)'
d.expression = d.expression   # 强制重编译, 避免 depsgraph 缓存旧闭包
```

混合节点 Factor 读取该 Value 节点 → factor 在 517~657=1, 其余=0。

### 2.3 持久化(重启不失效)

把 `grad_window` 定义写成一个**Register 文本块**(`use_module=True`)+ 偏好设置开
**Auto Run Python Scripts**,保存 .blend 后重启会自动注册,驱动照常生效、不报红。

---

## 3. 关键坑(Blender 5.2 全部实测)

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **Value 节点用关键帧不生效** | 对 `outputs[0].default_value` `keyframe_insert` 后,fcurve 求值看起来对,但 **Slotted Action 下评估值恒定不变**(原始节点与 depsgraph 评估都是默认值)→ 用户看开关一直是 1 | 改挂 SCRIPTED 驱动,表达式内调用命名空间函数读 `scene.frame_current` |
| **重新注册函数后驱动不重算** | 换/改命名空间函数后,已挂的驱动仍按旧闭包求值 | `d.expression = d.expression` 强制重编译 |
| **验证读了原始值** | 直接读 `node.outputs[0].default_value` 得到的是未动画的默认值 | 用 `depsgraph.id_eval_get(mat)` 读**评估值**(真实渲染值) |
| **5.2 Action 是 Slotted 结构** | `action.fcurves` 已移除,`action.slots[].fcurves` 也不存在 | 读关键帧走 `action.layers[].strips[].channelbag.fcurves` |

## 4. 一键复用

`scripts/frame-window-time-switch/` 的 `build_frame_window_switch.py` 自动完成 §2 全流程:
按 `WINDOW` 生成并持久化 `grad_window` → 给目标材质 Value 节点挂驱动 → 评估值逐帧验证。

```bash
python send.py build_frame_window_switch.py
```

改顶部 `MAT_NAMES / NODE_NAME / WINDOW` 即可复用到别的材质与帧区间。
