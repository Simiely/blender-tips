# 材质参数统一控制器与实时面板

> 适用于:多个材质共用**一个圆心 + 一套参数**的同心圆/径向发光体系,并要一个能**实时拖动**的 UI 面板。
> 做法 = 控制空物体(自定义属性)→ 材质节点 SCRIPTED 驱动 → Register 文本块面板,参数一处改、三处(多材质)同步。

---

## 1. 场景

场景里多个网格面板(如主装置的一部分)要像一个整体:一圈同心圆从**同一个世界圆心**向外扩散,
所有面板身上的环是同一道波。参数(扩散速度、环密度、发光强度、纯色亮度、开/关)想统一控制,
且希望拖一个滑块**实时**看效果,而不是靠打关键帧。重启 Blender 后面板与参数不能丢。

只求"一个材质的环",可以用仓库既有 `docs/材质与驱动规范.md` §4 的控制空物体方案;
本文档的可复用点在于:**多材质共用圆心 + 实时 UI 面板 + 重启持久化**,以及核心坑「改属性不重算」。

---

## 2. 做法

### 2.1 圆心与参数载体:一个控制空物体

```python
ctl = bpy.data.objects.get("主装置_圆环控制")
if ctl is None:
    ctl = bpy.data.objects.new("主装置_圆环控制", None)
    bpy.context.collection.objects.link(ctl)
ctl["speed"]       = ctl.get("speed", 0.01)      # 扩散速度(每帧)
ctl["gradient_on"] = ctl.get("gradient_on", 1.0) # 1=渐变圆环, 0=纯色
ctl["density"]     = ctl.get("density", 1.0)     # 环密度
ctl["gain"]        = ctl.get("gain", 25.0)       # 发光强度
ctl["solid"]       = ctl.get("solid", 20.0)      # 纯色亮度
```

**它同时是共用圆心**:所有材质的 `纹理坐标.Object` 都指向它。Object 坐标 = 世界坐标相对该空物体,
动它就整体对心;多材质只要都引用它,环就天然同心。

### 2.2 材质节点管线(XZ 径向同心圆)

```
纹理坐标(Object=控制空物体) → 取 X、Z → 组合2D → 长度(半径 r)
r × density(环数) → − expansion(扩张) → FRACT(分带)
  → ColorRamp(软化环带, B-Spline + 最暗处10%白) → × gain → 发光强度
  → 与 solid(纯色) 按 gradient_on 混合 → 自发光
```

- **扩张驱动**:`(frame - 1) * speed`,播放时环从中心向外推进;
- **其余参数驱动**:`density / gain / solid / on` 直接等于对应属性(SINGLE_PROP 指向控制空物体);
- 这样**同一个控制空物体**同时决定了圆心、速度和形貌 → 多材质一整套参数联动。

### 2.3 实时 UI 面板(Register 文本块)

材质节点驱动引用的自定义属性,**改数值不自动触发驱动重算**。解法是面板在 draw 里检测变化后强制刷新:

```python
class RING_CTRL_PT_controls(bpy.types.Panel):
    _last = {}
    def draw(self, context):
        ctl = bpy.data.objects.get("主装置_圆环控制")
        for key, label in [("speed","扩散速度"), ...]:
            self.layout.prop(ctl, '["%s"]' % key, text=label)
        # 检测到任一属性变化 → 强制刷新依赖图
        changed = any(RING_CTRL_PT_controls._last.get(k) != ctl.get(k)
                      for k in ("speed","density","gain","solid","gradient_on"))
        if changed:
            ctl.update_tag(); bpy.context.view_layer.update()
```

面板是**运行期注册**,重启会丢;把它作为文本块存进 .blend 并勾 Register(`use_module=True`)、
开启 Auto Run Python Scripts,重开文件即自动注册。

## 3. 坑(全部实测)

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **改自定义属性驱动不重算** | 脚本/属性面板直接改 `speed`,驱动数值纹丝不动 | 必须 `ctl.update_tag()` + `bpy.context.view_layer.update()`;放面板 draw 里每次拖动自动刷 |
| **`frame` 变量可用** | 本工程 5.2 的 SCRIPTED 驱动表达式里 `(frame-1)*speed` 正常(35.95=720×0.05) | 若遇到取不到再按仓库规范用 SINGLE_PROP 指向 `scene.frame_current` |
| **共享圆心** | 不同网格各自用自己 Object 坐标 → 环不同心 | 全部 `tex.object = 控制空物体`;控制空物体要处于共用圆心,且 scale=1、无旋转 |
| **重启面板丢失** | 只临时 `register_class`,关 Blender 就没了 | Register 文本块(`use_module=True`)+ Auto Run,源码随 .blend 保存自动重注册 |

## 4. 一键复用

`scripts/ring-control-panel/` 里的 `build_ring_controls.py` 自动完成 §2 全流程:
建控制空物体(保留已有属性)→ 重建指定材质为同心圆管线 → 注入 Register 面板文本块。

```bash
python send.py build_ring_controls.py
```

改文件顶部 `MAT_NAME / CTRL_NAME / PREFIX` 即可复用到别的材质;
同一体系的其它材质把 `tex.object` 指向同一控制器、参数驱动指向同一控制器即可并列。
