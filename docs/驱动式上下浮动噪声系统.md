# 驱动式上下浮动噪声系统(Blender 5.2)

> 给一组独立网格物体加**丝滑有阻尼感的上下浮动**驱动:每个物体围绕自己原位置平滑上下漂,
> 分层为「全局大波(整体趋势)+ 局部错动(各自错开)」,全部参数做成滑块实时调,可一键换花样。
> 可复用脚本包见 `scripts/driver-bob/`(含 `bob_driver.py` / `build_bob_drivers.py` / README)。

## 场景

点位模型 / 阵列装置里有一堆独立对象,希望它们:

- **各自独立上下移动**,但**不是匀速机械**,而是丝滑、有惯性、像悬浮一样有机地动;
- 每个物体**错位**(相位不同),用不同种子测试不同效果;
- 能统一控制:**最大上移 / 最大下移**(可不对称)、**移动速度**、**速度随机范围**、
  **种子(换花样)**、以及「整体趋势 vs 各自错动」的强弱;
- 方便调试:滑块一拖、时间轴一 scrub 立刻看效果,不烘焙关键帧;
- 部分对象(「不修改」空物体子树)完全不动,自动排除。

## 原理(为什么是丝滑 + 阻尼感)

**不是「判断」出来的条件分支,而是把随时间平滑滑动的连续信号直接映射成位移**:

```
c = clamp( (全局权重 × 全局噪波 + 局部权重 × 局部噪波) / 总权重 , -1, 1 )
位移 = c × 最大上移   (c ≥ 0 向上)
      c × 最大下移   (c < 0 向下)
location.z = 基准Z + 位移
```

- **连续无突变**:`c` 由 Perlin 类噪波(`mathutils.noise.noise`)随时间取样,本身在 −1~1 间平滑来回,所以位移天然连续 → 这就是「丝滑」。
- **阻尼感来源**:噪波在**过 0(中点)变化最快、到 ±1(顶点)变化最慢** → 物体经过中点快、接近极限缓下来再回头,读起来就是缓入缓出的惯性,而非机械匀速。

### 两层结构(关键)

| 层 | 含义 | 参数 |
|---|---|---|
| **全局大波** | 一个共享低频信号,所有物体**整体同频**地缓缓上下漂 → 「大趋势」 | 全局大波权重 / 全局频率 |
| **局部错动** | 每个物体叠加**各自种子**驱动的噪波,做幅度更小、彼此错开的微动 → 「层次不齐」 | 局部错动权重 / 局部频率 / 种子偏移 |

两层加权混合 → 既统一又有随机感,不会全乱。

## 做法(可复用脚本)

### 1. 核心噪波函数 `bob(frame, self)`(注册进驱动命名空间)

完整源码见 `scripts/driver-bob/bob_driver.py`。要点:

- 每个网格物体存 `bob_ctrl`(指向自己集合的控制面板)、`bob_base_z`(静止位置)、`bob_seed`(独立种子)、`bob_rand`(随机速度因子);
- 时间流速 `t = frame × 速度 × (1 + 随机因子 × 速度随机范围)` → 每个物体速度不同(错动第一层);
- 全局噪波输入完全相同(整批同频),局部噪波输入带各自 `seed`(相位错开);
- 加权混合 → clamp → 按符号选上下限 → 返回 `基准Z + 位移`。

### 2. 通用构建器 `build_bob_drivers.py`

```python
TARGETS = [
    ('主装置01', '运动控制01', '不修改'),   # (集合名, 控制面板名, 不动区名包含)
    ('主装置02', '运动控制02', '不修改'),
    # ...
]

# 每个集合: 新建控制面板空物体(9 个中文滑块, 默认值已写入)
#          + 给运动网格挂 Z 驱动(表达式 bob(fr, self))
#          + 名字含『不修改』的 EMPTY 子树自动排除
```

运行(经桥或 Scripting 工作区 Run Script):
```bash
python send.py build_bob_drivers.py
```

- 驱动变量用 `d.use_self = True`,表达式 `bob(fr, self)`,`fr` 由 `SINGLE_PROP` 读 `scene.frame_current`;
- **幂等**:已有驱动的物体跳过,不会重置基准 Z / 种子;固定随机种子 → 重建花样一致。

### 3. 控制面板(实时调)

选中 `运动控制0X` 空物体 → 属性面板 → 自定义属性,9 个滑块见脚本包 README。

## ⚠️ 坑(代码里看不出,全是实战踩的)

- **Blender 5.2 驱动变量无 `SELF` 类型**:旧写法 `vf.type='SELF'` 报非法类型。正确做法 `d.use_self=True`,表达式里 `self` 即可用。
- **自定义属性显示名就是键名**:想中文 UI 直接把键设成中文(`obj['最大上移']=1.0`),`id_properties_ui().update(name=...)` **不接受** `name` 参数,改显示名只能改键本身。
- **改名控制物体 / 替换 bob 函数后,旧驱动会"陈旧"**:depsgraph 不把旧驱动标记为需重算,求值直接返回基准值(看似不动)。修复:给每个 Z 驱动调一次 `driver.update()`(不动 seed/基准)。
- **`bob()` 不随 .blend 保存**:驱动依赖注册进 `bpy.app.driver_namespace` 的函数,重开文件函数丢失 → 驱动变红。必须用文本块 `bob_driver.py` 勾 Register 持久化,或手动 Run Script 一次。
- **基准位置 `bob_base_z` 只在首次记录**:重建时若已存在则保留,避免把被驱动"当前值"误当基准(否则会跳原点)。
- **`mathutils` 要在定义 bob 的脚本里 import**:驱动命名空间里 `noise` 可用的前提是 `bob_driver.py` 顶部 `import mathutils`;别像临时脚本那样依赖"之前 exec 过"的全局残留。
- **桥只改内存**:构建完记得 Ctrl+S(尤其 `bob_driver.py` 文本块 + 控制面板属性)。

## 验证要点

- 扫帧验证所有物体偏移**严格落在 ±上下限内**(实测 5 集合 × 150 帧 × 各网格,越界 0 次);
- 同一帧各物体偏移**互不相同**(错动生效);
- 「不修改」子树**跨帧完全静止**。
