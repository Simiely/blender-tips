# 视口预览录制(录屏式,非全渲染) · Blender 5.2

> 一键导出**当前相机视角**的视口预览视频:走 `bpy.ops.render.opengl`,抓的是视口
> 显示样式(实体/SOLID 等),**不进灯光渲染**,速度快,相当于"录屏"。
> 可复用脚本见 `scripts/playblast/playblast_export.py`。

## 场景

- 给甲方 / 自己**快速看动画效果**,不想等 Cycles 全渲染;
- 想导出的是"我打的相机"拍出来的画面(带机位切换),而不是当前 3D 视口;
- 出一段能直接发群里 / 塞进汇报的轻量 mp4。

## 原理

Blender 的 `render.opengl` 运算符专门做"视口抓取":

- `animation=True` → 按时间轴逐帧抓取,合成视频;
- `view_context=False` → **从场景活动相机出画面**(你要的"我打的相机"视角);
  若用 `view_context=True` 则抓的是当前 3D 视口(可能没锁相机、带 UI)。
- 输出走 FFMPEG 视频编码,不依赖合成器节点树,也不进灯光渲染,所以极快。

## 做法

1. 把想要的机位设成**场景活动相机**(选中相机 → `Ctrl+Numpad0`;机位按帧切换的动画会自带)。
2. 打开 `scripts/playblast/playblast_export.py`,改顶部:
   - `OUTPUT_PATH` —— 输出文件名(默认 `E:/desktop/视口预览.mp4`)
   - `WIDTH, HEIGHT` —— 分辨率(默认 1920×1080)
3. Scripting 工作区 **Run Script**(Alt+P)。状态栏显示进度,完事打印 `PLAYBLAST_DONE`。

录制范围 = 时间轴的预览/渲染范围(`frame_start`~`frame_end`),和渲染动画一致。

## ⚠️ 坑(代码里看不出,全是实战踩的)

- **Blender 5.2 输出配置顺序**:必须先 `image_settings.media_type = 'VIDEO'`,
  **再** `image_settings.file_format = 'FFMPEG'`。顺序反了直接报
  `'FFMPEG' not found in enum`(因为 VIDEO 之前该枚举项还没就绪)。脚本已按正确顺序。
- **`view_context` 选错**:`False` = 相机视角(你要的);`True` = 当前视口(可能不对)。
- **`s.camera` 为空时的兜底**:脚本在 `s.camera is None` 时自动取场景里第一个 CAMERA 对象,
  仍没有则退回视口抓取并打 WARN。正式出片前请确认活动相机正确。
- **路径中文 / 目录不存在**:Windows 下建议 `OUTPUT_PATH` 用英文路径,且目录已存在,
  否则 FFMPEG 写文件失败(无明显报错,文件 0 字节)。
- **帧率取场景 `render.fps`**:脚本只设分辨率;改帧率去输出属性面板。
- **音频 `NONE`**:纯视口预览无声;要带声改 `s.render.ffmpeg.audio_codec`。

## 调试建议

- 想录"我当前看到的视口"而非相机 → 把 `view_context=False` 改成 `True`
- 输出空白 / 打不开 → 确认 `OUTPUT_PATH` 目录存在、路径无中文编码问题
- 想换格式 / 透明 → 改 `ffmpeg.format` / `ffmpeg.codec`(如 `QUICKTIME` + `QTRLE`)
- 复杂场景掉帧属正常(实时视口抓取);要稳就降分辨率或简化显示样式
