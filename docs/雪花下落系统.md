# 雪花下落系统（参数化连续下落 + 真实雪速 + 循环回卷 + 顶部入场缩放）

> 来源：下雪工程实战（Blender 5.2 远程 9878 桥工程，Eevee 渲染）
> 适用：Blender 5.2 LTS，Eevee / Cycles 均可（几何节点驱动，与引擎无关）
> 关键词：几何节点、Mesh to Points、Instance on Points、Object Info(RELATIVE)、FLOORED_MODULO、Scene Time、随机落点、循环回卷、低模源隐藏

---

## 零、一句话

在**地面参考平面**上方按真实雪速（~0.5 m/s）**连续下落** N=50000 片低模雪花：
每片从「天空（地面+30m）」匀速飘到「地面」，**触地瞬间回卷到天空**（无半空消失、无顶部堆积），
顶部做 0→满 的**入场缩放**；邻居线程是：一个**隐藏的单面低模雪花源 + 一个 EMPTY 宿主上的单个几何节点组**。
所有对象归拢到独立集合 `下雪_系统`，可整体复制迁移到其他工程。

---

## 一、场景

活动场景中需要持续的飘雪效果，要求：

- 雪花**连续、均匀**铺满整个 XY 区域，从天空落到地面，**不悬停、不堆积在顶部**
- 速度符合真实雪花（~0.5 m/s，慢速飘落，不是"下雨"的快速下坠）
- 落雪区域足够高（30m），雪花**贴地后再消失（触地即回卷到顶部）**，不在半空消失
- 数量大（5 万片）且性能可控 → 用**低模平面雪花 + 实例化**，不逐片建对象
- 每片雪花朝向合理（近似平行地面、随机自旋），平视也看得到雪花平面
- 雪花源对象本尊不渲染（源用于生成几何，画面只见散布实例）

---

## 二、总体架构

核心思想：**「源对象」只负责提供低模雪花几何（被隐藏），「宿主上的下雪_GN」生成点阵 →
逐点算位置/相位/朝向/缩放 → 实例化源几何**。全部下落逻辑在一个几何节点组里用
`Scene Time` + 随机相位完成，**宿主只是一个变换锚点（EMPTY）**。

```
平面.005(地面参考, 提供 XY 足迹 + 地面高度 = 落雪范围)
下雪_宿主(EMPTY, 变换必须清零, 挂「下雪_GN」NODES 修改器)
  └─ 下雪_GN  → 栅格(MeshGrid, 250×200 点) → 转点
       ├─ 每点显式接 Index → RandomValue 相位 / X / Y / 倾角 / 自旋(独立种子)
       ├─ prog = FLOORED_MODULO(Seconds/CYCLE + 相位, 1)   # 全体匀速下落 + 触地回卷
       ├─ Z = GROUND + (1 - prog) * FALL_SPAN               # 天空=地面+30m
       ├─ 顶部入场缩放 = MapRange(prog 0~2% → scale 0→满)
       ├─ 随机朝向: 倾角(≈垂直/平行Z, ±抖动) + 绕Z随机自旋
       └─ 实例化于点上(Instance=花瓣雪花_低模[RELATIVE], Scale=入场, Rotation=朝向)

花瓣雪花_低模(源 MESH, 26 顶点低模雪花, hide_render=True / hide_viewport=True / visible_camera=False)
```

调用链：`Scene Time → CYCLE 归一 → +随机相位 → FLOORED_MODULO 回卷 → 线性映射到 Z → 顶入场
→ 实例化源几何(继承源缩放) → 每片独立随机朝向` → 渲染。

## 三、对象与数据块清单（都在「下雪_系统」集合）

| 对象 | 型别 | 关键配置 | 作用 |
|---|---|---|---|
| `下雪_宿主` | EMPTY | loc=(0,0,0), rot=(0,0,0), scale=(1,1,1)；NODES 修改器 `下雪_GN` | 落雪**引擎**（几何节点宿主） |
| `花瓣雪花_低模` | MESH | 26 顶点低模雪花(平展, 局部 Z≈0)；**`hide_render=True` / `hide_viewport=True` / `visible_camera=False`**；浅蓝材质 | 雪花几何**源**，不渲染 |
| `平面.005` | MESH | 世界包围盒底部 Z 即地面高度(-1.3m)，XY 足迹即落雪范围 | 地面**参考**（锚定落雪区） |

依赖的数据块（复制时一起带走）：节点组 `下雪_GN`；材质 `花瓣雪花_低模_mat`；网格 `花瓣雪花_低模`。
用 `scripts/snowfall-scatter/pack_snow_collection.py` 可一键把宿主/源/地面参考归拢进 `下雪_系统` 集合。

## 四、参数配置（build_snowfall.py 顶部）

| 参数 | 默认(实况) | 作用 |
|---|---|---|
| `SNOW_NAME` | `花瓣雪花_低模` | 雪花源网格（26 顶点低模） |
| `PLANE` | `平面.005` | 地面参考（XY 足迹=落雪范围，底部 Z=地面） |
| `N_X, N_Y` | 250, 200 | 生成点（250×200 = **50000**） |
| `FALL_SPAN` | 30.0 | 下落高度跨度（天空 = 地面 + 30m） |
| `CYCLE` | 60.0 | 一次完整下落的秒数（30m/60s ≈ **0.50 m/s** 真实雪速） |
| `FADE_FRAC` | 0.02 | 顶部入场缩放窗口（prog 0~2% 内 scale 0→满） |
| `FLAKE_SCALE` | 0.6 | 实例缩放（低模源外径 0.16 × 0.6 = 半径≈0.096m） |
| `VERT_TILT` / `TILT_JITTER` | 90 / 15 | 雪花倾角（度）±随机抖动：默认垂直/平行 Z |
| `FACE_SPIN` | 360.0 | 绕 Z 随机朝向（度） |

节点内固定量：`prog` 的 `FLOORED_MODULO` 模数=1.0；`1/CYCLE` 缩放；`zsub` 初值 1.0；`zadd` 初值 GROUND；
`mapr From[0, FADE_FRAC] → To[0, FLAKE_SCALE]`。随机种子：相位 29、X 7、Y 13、倾角 401、自旋 509（X/Y 独立）。

改数量/速度/高度/大小/朝向只需改顶部参数重跑 `build_snowfall.py`（幂等重建整个节点组）。

## 五、几何节点结构（下雪_GN，23 节点）

### 5.1 落点生成与位置

```
栅格(MeshGrid: Size 1×1, Vertices 250×200)
  → 网格转为点(MeshToPoints)
  → 设置位置(SetPosition, Position=合并XYZ:
        X=RandomValue[ID←Index, 种子7, Min/Max=世界包围盒中心±半宽]
        Y=RandomValue[ID←Index, 种子13, 同理]
        Z=GROUND + (1-prog)*FALL_SPAN)
```

### 5.2 下落相位与回卷（核心）

```
Scene Time(Seconds) → 运算[× 1/CYCLE] → 运算[+ 相位RandomValue(种子29, 0~1)]
  → 运算[FLOORED_MODULO 1] → 得到 prog ∈ [0,1)
Z = GROUND + (1 - prog) * FALL_SPAN    # prog=0 在最顶(天空), prog→1 到地面
```

**每次触地(prog 从 ~1 回卷到 0)雪花瞬间回到天空，实现"贴地后消失、循环下落"**，
无半空消失；每片相位随机 → 初始就铺满整条高度列，不会等在顶部。

### 5.3 顶部入场缩放

```
prog → 映射范围(MapRange From[0, FADE_FRAC=0.02] → To[0, FLAKE_SCALE=0.6], clamp)
  → 合并XYZ(三轴同入) → 实例化于点上 Scale
```

新"出生"的雪花(prog≈0)从 0 缩放到满，避免顶部突然冒出一个个小点；到达地面时已是满尺寸。

### 5.4 朝向

```
随机值[ID←Index, 倾角 90°±15°] → 合并XYZ.X   # 近似平行地面(垂直Z), 平视也看得到平面
随机值[ID←Index, 自旋 0~360°] → 合并XYZ.Z     # 绕 Z 随机自旋, 防千篇一律
```

### 5.5 主链

```
设置位置(点) → 实例化于点上(Points=点, Instance=物体信息[花瓣雪花_低模, RELATIVE],
             Scale=顶部入场, Rotation=朝向) → 组输出(Geometry)
```

`ObjectInfo` 必须 **RELATIVE** 空间：这样散布实例继承源对象缩放与变换；换 ORIGINAL 会忽略源缩放。

## 六、行为与物理量（实测）

- 实例数：**50000**（250×200）
- 落雪范围：地平面 `平面.005` 世界包围盒 Z=-1.3m（地面）→ 天空 = -1.3+30 = **28.7m**
- 下落速度：30m / 60s ≈ **0.5 m/s**，落在真实枝晶雪花末速度范围(0.3~0.6 m/s)内
- 抽样实测（本地桥 9878，`probe_snow.py`）：frame 1/75/150 均为 **n=50000**，
  `Z[-1.30, 28.70]`（精确贴地到地面 -1.30，到顶 28.70）—— 说明**无半空消失、无顶部堆积**

## 七、复用时注意（坑）

1. **宿主必须是 EMPTY 且变换清零**：落雪区高度严格锚定地面参考平面(GROUND)。宿主若被移动（如本工程曾出现 Z=-1.47），整个雪区会整体下移，**雪会埋进地面**、顶部也够不到天空。`build_snowfall.py` 会强制清零宿主 loc/rot/scale。
2. **源雪花三连隐藏**：`hide_render=True` + `hide_viewport=True` + `visible_camera=False`。
   只藏"相机直接渲染"的本尊，散布实例经 `ObjectInfo(RELATIVE)` 照常渲染。
3. **RandomValue 必须显式接 Index 作 ID**：相位 / X / Y / 倾角 / 自旋 共用点的唯一编号作 ID 输入，
   并提供**不同的种子**——否则坐标相关(如 X 与 Y 强相关)会成线性分布、或全部同相位堆积在顶部。
4. **触地用 FLOORED_MODULO，不要加贴地淡出**：贴地是「prog=1 → 取模回 0（回天空）」。
   若在半空加 `MapRange` 淡出，会出现"雪花还没到地面就消失"的视觉错误。
5. **位置偏移经 `设置位置` 施加在实例化前的点上**，别直接改 `实例化于点上` 的 Position（会被实例基缩放放大）。
6. **缩放在实例化于点的 Scale 上做**（顶部入场 `MapRange → 合并XYZ`），而不是给源对象加 scale 动画——实例化后缩放与源缩放叠加。
7. **改了数量后 `N_X×N_Y`==50000 是硬判据**：`verify_snow.py` 会断言实例数精确等于 50000，并抽查 3 帧 Z 贴地 `[-1.30, 28.70]`。
8. **桥 120s 上限**：`verify_snow.py` 内部抽样 3 帧（frame_set + depsgraph 遍历），在有大量对象场景下可能接近上限；超时后重跑同一脚本（只读、幂等）以新请求为准。改完必须**分两次请求**验证（读未刷新缓存值会误导）。
