# 材质与驱动规范(灯光材质系统)

> 适用于:灯光装置类项目(灯1~灯11 阵列)的程序化发光材质 + 动画驱动。
> 本文档是**复用/修改的操作手册**——按灯组复制材质时照着做就不会出错。

---

## 1. 材质命名规范(强制)

**每个灯组的材质互相独立分管,即使内容完全相同也不共享材质块。**

| 规则 | 示例 |
|---|---|
| 灯组前缀命名 | 灯4 的材质 = `灯4_滚筒灯光`;灯6 的 = `灯6_滚筒灯光` |
| 独立材质块 | `灯4_滚筒灯光` 和 `灯6_滚筒灯光` 是**两个不同材质**,互不影响 |
| 副本后缀 | 给错组/需要独立调整的副本 = `灯X_材质名.001`(Blender 自动 .001/.002) |
| 禁止跨组命名 | 灯6 底下的对象**绝不能**挂 `灯4_xxx` 材质 |

**为什么独立**:不同灯组位置不同(中心坐标/高度范围不同),材质参数(TexCoord/VNorm)必须按各自位置计算,共享材质会导致条纹错位。

## 2. 圆柱投影核心公式

```text
u = (atan2(y, x) + π) / 2π        # 角度归一化 0~1, 环绕一圈
v = (z - zmin) / (zmax - zmin)    # 高度归一化 0~1
f = u×K + v×N                     # 螺旋条纹值(K环绕圈数, N高度条纹数)
f = f mod 1  (用 FLOORED_MODULO!) # 循环取模,负值正确
条纹 = ColorRamp(f)               # 黑白/灰度/三分法
```

**节点链**:
```
TexCoord(Object) → SeparateXYZ → atan2(Y,X) → +π → ÷2π → u(角度)
                  └→ Z → 高度归一化(Add -zmin, Multiply 1/h) → v
u ± v → Mod → ColorRamp → RGB转灰度 → Multiply(强度倍数) → Emission Strength
```

**参数含义**:
| 参数 | 节点 | 作用 |
|---|---|---|
| K | MultK | 环绕圈数(条纹绕柱圈数) |
| N | MultN | 高度条纹数 |
| ± | SpiralAdd | ADD=右下到左上, SUBTRACT=左下到右上(方向) |
| Mod | SpiralMod | **必须 FLOORED_MODULO**(普通 MODULO 负值会裁剪) |

**条纹角度速查**(K:N 比例):
| K:N | 角度 |
|---|---|
| 1:4 | ≈14°(近平) |
| 1:2 | ≈27° |
| 2:2 | 45° |
| 3:2 | ≈56° |

## 3. 按位置适配(⚠️ 复制材质到新灯组必做!)

材质复制到**另一个灯组**后,必须修改两处,否则条纹错位:

### 3.1 TexCoord.object = 该灯组的中心空对象
```python
tex.object = D.objects["灯6_选中组"]   # 该组自己的中心空物体
```
Object 坐标 = 世界坐标相对该空物体的坐标 → 角度/高度按本组中心算。

### 3.2 VNormAdd/VNormMul 按本组 Z 范围重算
```python
zs = [c.matrix_world.translation.z - center_obj.location.z for c in children]
zmin, zmax = min(zs), max(zs)
vadd.inputs[1].default_value = -zmin          # VNormAdd
vmul.inputs[1].default_value = 1.0 / (zmax - zmin)   # VNormMul
```

> 案例:灯1 高1.95m 的 VNorm 是 1.196/0.512;灯6 高 2.55m 需改成 1.327/0.393;
> 灯4 高 1.29m 需改成 0.982/0.776。**照抄灯1 参数 = 条纹上下分布错误。**

## 4. 驱动速度控制(改数字立即生效)

用户改**控制空物体自定义属性**的数字 → 动画速度立即变化(无需关键帧)。

### 方案 A:对象级 driver(推荐,稳定)
```python
ctrl["rot_speed"] = 1.2    # 度/帧 (300帧转一圈 = 1.2)
ctrl["up_speed"] = 0.0065  # 米/帧

# 空物体 rotation_euler.z 的 driver:
drv_r.expression = 'frame * rot_speed * 0.0174533'
# 空物体 location.z 的 driver:
drv_z.expression = '1.2 + frame * up_speed'
```
然后纹理坐标源指向该空物体(或用材质内偏移方案 B)。

### 方案 B:材质节点 driver(旋转条纹必须用这个!)
**条纹旋转不能靠转空物体**(Object 坐标只跟随平移!),必须在材质节点内偏移:
```
uOffset = Math(ADD): u + offset
vOffset = Math(ADD): v + offset
```
```python
nt.driver_add('nodes["UOffset"].inputs[1].default_value')  # ⚠️ 路径规范见 §5
drv.expression = 'frame * rot_speed / 360'
```

### 控制点操作
选中控制空物体 → 属性面板(橙色三角) → 自定义属性:
- `rot_speed` = 旋转速度(度/帧), 0 = 停, 负 = 反向
- `up_speed` = 上升速度(米/帧), 0 = 停, 负 = 下降

## 5. ⚠️ 三大坑(全部实测确认)

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **Object 坐标不跟随旋转** | 旋转空物体 90°,条纹毫无变化 | 旋转动画走材质节点内偏移(§4 方案B),空物体只用于平移 |
| **材质 driver 路径必须 inputs[N]** | `inputs["Location"]` 报 not found | `nodes["节点名"].inputs[1].default_value`(数字索引) |
| **取模用 FLOORED_MODULO** | 普通 MODULO 负值被钳制→条纹底部"裁剪" | 循环类计算一律 FLOORED_MODULO |

## 6. 灰度/颜色渐变(三分法)

**循环渐变通用公式**:等分数 = 颜色数 × 4;首尾同色 = 无缝循环;插值必须 LINEAR。

**黑白灰三分法**(强度 0/0.5/1 三档):
| 位置 | 强度 | 段 |
|---|---|---|
| 1/12 | 0.0 黑 | 黑平台 |
| 3/12~5/12 | 0.5 灰 | 灰平台 |
| 7/12~9/12 | 1.0 白 | 白平台 |
| 11/12 | 0.0 黑 | 黑平台(衔接) |

**白膜材质**(预览用):
```python
pnode.inputs['Base Color'].default_value = (1,1,1,1)
pnode.inputs['Emission Color'].default_value = (1,1,1,1)
pnode.inputs['Emission Strength'].default_value = 1.0
```

## 7. 打组/挂载规范(材质挂载前提)

```python
# 空对象定位到组子对象包围盒中心
# 挂载必须手动 mpi(否则世界位置翻倍错位!)
inv = empty.matrix_world.inverted()
for o in objects:
    o.parent = empty
    o.matrix_parent_inverse = inv
```

**复制集合时注意**:复制出来的空对象在原点(0,0,0),子对象挂载后移动空物体会整体错位——先解除旧父级,再按 §3 重新定位挂载。

## 8. 快速复用清单(新灯组应用滚筒材质)

```text
1. 复制材质: 灯X_滚筒灯光 = 灯1_灯光新.copy()
2. TexCoord.object = 灯X 中心空对象(§3.1)
3. VNormAdd/VNormMul 按灯X Z 范围重算(§3.2)
4. 命名: 灯X_滚筒灯光(独立块,不共享)
5. 驱动: 继承或新建控制空物体 rot_speed/up_speed(§4)
6. 验证: 播放看条纹旋转+上升是否正常
```
