# 输出路径与序列帧输出规范

> 适用于:需要统一渲染/录屏输出路径的工程(如 5 个主装置灯光工程)。
> 规范:输出路径统一用**相对路径**(`//` 前缀),序列帧用 `#` 占位命名,避免绝对路径与手工拼接。
> 与 @docs/技巧速查.md §7(合成器与渲染输出)配套,本文侧重 **`render.filepath` 与输出格式本身**的正确配置。

---

## 1. 输出路径规范(强制)

**所有输出用相对 blend 工程文件的路径,不用绝对路径**——工程整体移动/换机后,输出自动跟随工程目录,不会因为换目录而失配。

| 项 | 规范 | 示例 / 说明 |
|---|---|---|
| 相对前缀 | 路径以 `//` 开头 | `//output/260821x01/...` |
| 目录结构 | `output/<批次标识>/` | 批次如 `260821x01`(日期 + 序号) |
| 文件名 | `<标识>####` | `#` 是帧号占位 |
| 帧号补零 | 默认 4 位,用 `#` 数量自定义 | 1 个 `#`=1 位;`####`=0001 |
| 扩展名 | 开 `use_file_extension` 自动加 | 格式设 PNG 后自动 `.png` |

`//` 前缀 = 当前 blend 文件所在目录,输入 `//` 即在工程目录下;`#` 是帧号占位符(官方帧号默认在文件名末尾补 4 位零)。

**期望产物**:`outdir/260821x010001.png`、`...002.png` …(帧序列)。

---

## 2. 正确设置顺序(Blender 5.2 实测)

> ⚠️ 顺序是文件格式"怎么设都报错/输出格式不对"的**最常见根因**,务必按序。

```python
import bpy
sc = bpy.context.scene
is_ = sc.render.image_settings

# ① 先设 media_type,再设 file_format —— 顺序反了枚举未就绪,直接报 enum not found
is_.media_type   = 'IMAGE'      # 图片序列;录视频则 'VIDEO' + 'FFMPEG'(见坑1)
is_.file_format  = 'PNG'        # media_type=IMAGE 后 PNG/EXR/JPEG 等图像格式才可写

# ② 输出路径:相对路径 + 帧序列占位 + 自动扩展名
sc.render.filepath = '//output/260821x01/260821x01####'
sc.render.use_file_extension = True

# ③ 复核:打印解析后的绝对路径,确认落盘位置
print(bpy.path.abspath(sc.render.filepath))
# -> E:/工程目录/output/260821x01/260821x010001.png  (帧号插入 #### 位置)
```

### 坑 1 —— media_type 决定枚举域

`media_type`:
- `IMAGE` → 图像序列(可选 PNG / OPEN_EXR / JPEG …)
- `VIDEO` → 仅 `FFMPEG`(视频)
- `MULTI_LAYER_IMAGE` → 多图层 EXR

先设 `media_type` 再设 `file_format`,顺序反了直接 `'PNG' not found in ('FFMPEG')`。这与 AGENTS 中"5.2 视口录制先 `media_type='VIDEO'` 再 `file_format='FFMPEG'`"是同一机制的两个方向。

### 坑 2 —— 帧号补 4 位零、插在扩展名前

渲染动画时帧号补在文件名**末尾、扩展名之前**,默认补 4 位零。想自定义位宽就用对应数量的 `#`:

| 写法 | 产物 |
|---|---|
| `260821x01.png`(无 #) | 动画渲染只写一帧、后帧覆盖(等于没序列) |
| `260821x01####` | `260821x010001.png`(4 位,标准) |
| `260821x01_##` | `260821x01_01.png`(2 位) |

## 3. 远程桥联调设置方法

用 `python send.py <脚本.py>` 发送完成即可(桥脚本在 `scripts/blender-remote-control/`)。脚本里把 `media_type / file_format / filepath` 一步全设好,末尾打印 `bpy.path.abspath()` 校验。注意桥端脚本**不要写 `if __name__=='__main__':`** 守卫(桥接 exec 时 `__name__` 是 `builtins`,守卫会让脚本静默不执行)。

## 4. 核查清单

- [ ] 路径以 `//` 开头(相对)
- [ ] 目录为 `output/<批次>`
- [ ] 文件名含 `#` 帧占位(至少 1 个,建议 `####` 共 4 位)
- [ ] `media_type='IMAGE'` + `file_format='PNG'`(或目标图像格式),顺序正确
- [ ] `use_file_extension=True`
- [ ] `bpy.path.abspath()` 打印确认真实落盘目录
- [ ] F12 无输出时:**检查合成器是否残留"空节点组"(ghost 状态)**——5.2 `use_nodes` 恒 True,空 `compositing_node_group` 会让渲染结果**不写盘**(详见 AGENTS 有关条目)
