# 灯光链接排除某个物件：receiver 不是 blocker

> 来源：`261111xJ88G_animation_Extx01_03.blend` 实战（Blender 5.2.2 LTS / Windows，2026-11-12）
> 场景：一套「补光」集合里有 12 盏面光，需要它们只照车身、不把地面与背板照出一片亮斑。

---

## 0. 一句话结论

**让某盏灯不照某个物件，要用 `receiver_collection`（接收集合，白名单），
不是 `blocker_collection`（挡光体）。** 后者是"这个物件替这盏灯遮光/投阴影"，
勾上去画面反而变亮。

## 1. 做法

把"该被照亮的东西"放进一个集合，设为该灯的接收者：

```python
ob.light_linking.receiver_collection = coll   # 只照 coll 里的物件
```

排除地面 = 建一个「除地面之外的所有物件」的集合：

```python
recv = bpy.data.collections.new("补光_接收_不含地面")
for o in bpy.data.objects:
    if o.type != 'MESH':
        continue
    if o.name.startswith("地面_") or o.name == "背景环境":
        continue
    recv.objects.link(o)

for o in bpy.data.collections["补光"].objects:
    if o.type == 'LIGHT' and o.light_linking.receiver_collection is None:
        o.light_linking.receiver_collection = recv
```

> 只改「接收者为全体」的灯；本来就有窄接收集合的（只照某几件）不动。

## 2. 坑

### ★★★ `blocker_collection` 语义是"挡光体"，不是"不收光"

它相当于"这个物件替这盏灯遮光（投阴影）"。实测把车身加进 blocker 后，
车身区域亮度反而 **+5.6%**（方向相反）。想"排除"只能用接收集合。

### ★★ 接收集合是白名单，集合外完全不收光

所以"排除地面"要建"除地面之外"的集合，而不是"地面集合"。
另外要注意：一个物件的**包围盒**被另一个大物件包含，不代表被遮挡（本例 12 盏灯
的包围盒都落在 `背景环境` 的包围盒内，但实际并没有被挡）。

### ★ 灯本身不挡光

看到地面有阴影，要去找场景里的挡光**网格**。本例是一块 **1 个面、无厚度**的
`遮光面`（18.61 × 0.89 m，立在 y=-0.45，正好卡在灯与车之间），
不是灯的阴影 —— Cycles 里的灯是采样光源，不产生遮挡。

### ★ 门板灯（`light.cycles.is_portal`）不发光

只做采样引导。排查"这盏灯没效果"时先看这个开关。

## 3. 验证

同一盏灯、同一功率，切换接收集合，测目标区域亮度：

| 设置 | 地面/背板区域亮度 |
|---|---|
| receiver = 全体 | 0.63703 |
| receiver = 不含地面（97 个物件） | **0.15182** |

降 **76.2%**，且车身亮度不变 —— 这才是"排除地面"。

> 测法：把该灯临时提到 5000 W 放大差异、其它灯全关，再读画面下部区域 RGB 均值。
> 低功率灯直接测会被噪声淹没（1–50 W 的灯做同样操作只有 ±2% 波动）。

## 4. 实测数据

| 项 | 数值 |
|---|---|
| receiver=全体 → 不含地面 | 0.63703 → 0.15182（**−76.2%**） |
| blocker 误用（车身入挡光） | 车身区域 **+5.6%**（方向相反） |
| 接收集合规模 | 97 个物件（全部车体 + 辅助件，排除地面与背板） |
| 挡光网格 | `遮光面`：1 面、18.61 × 0.89 m、无厚度 |
