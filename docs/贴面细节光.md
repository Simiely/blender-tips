# 贴面细节光：小面光 + 渐变画高光

> 来源：`261111xJ88G_animation_Extx01_03.blend` 实战（Blender 5.2.2 LTS / Windows，2026-11-13）
> 场景：车模棚拍，金属漆的立体感不足；作者用两盏 1 W / 0.3 W 的小面光贴在前翼子板与腰线附近，
> 靠渐变把发光面收窄成一条亮带，在漆面上"画"出高光。

---

## 0. 一句话结论

**金属漆的立体感来自高光形状，不是整体亮度。** 做法是
**1 m² 面光 + 0.3–1 W + 渐变收窄成亮带 + 贴合 0.6 m**，
把一条可控高光"画"到指定曲面上 —— 比加大主光精准，也不破坏布光明暗关系。

## 1. 做法

1. **1 m² 面光，功率压到 0.3–1 W**（照射距离只有 0.6 m 左右，功率必须极低）。
2. 用 [主题 57](面光渐变发光面.md) 的渐变把发光面**收窄成一条亮带**（不是整面亮）。
3. **`light_linking.receiver_collection` 精确限定**到该亮的部件，
   例：只照 `车身_侧裙 / 车身_前挡风 / 背景环境`。
4. **贴合**：沿发光方向到表面的间隙控制在 0.6 m 内，方向尽量垂直于该处曲面。

## 2. 坑

### ★★★ 不要用瓦数判断这类灯重不重要

实测两盏 1 W / 0.3 W 的灯：单像素最大差 **0.50**、区域均值 **0.0094** ——
它们是"画面里有没有高光"的差别。按功率排序会把它们当垃圾清掉（本项目真的发生过）。

### ★★ 接收集合要小

这类灯只该影响 1–3 个部件；给「全体」会把整车均匀提亮，高光立刻消失。

### ★ 间隙过大（>1 m）直接失效

实测一盏方向偏了的细节灯，沿发光方向命中点距灯 **5.09 m**（打在背景板上），对车身零贡献。
判据：从灯位沿 `-Z` 做一次 `scene.ray_cast`，看命中距离与命中物。

## 3. 验证

关掉单盏灯后做**像素差分**，看差异落点是否与该部件在画面上的位置一致：

| 灯 | 差异峰值位置（画面 8×6 分区） | 强度 |
|---|---|---|
| 细节灯 A（1 W，朝 -Y，间隙 0.67 m） | 第 3 列 / 第 3 行 ≈ 前翼子板、前轮拱 | 区域均值 0.0057 |
| 细节灯 B（0.3 W，方向 (-0.74,-0.61,-0.28)） | 第 4 列 / 第 4 行 ≈ 前门上半、腰线 | 单像素最大 0.50，均值 0.0094 |

判据是"**落点对不对**"，不是"亮了多少"。

## 4. 实测数据

| 项 | 数值 |

| 功率区间 | 0.3 – 1 W（1 m² 面光） |
