# 问题：连续下雪(几何节点)想做到真实雪速 + 贴地循环 + 无半空消失

**TL;DR**:`SceneTime → ×1/CYCLE → +随机相位 → FLOORED_MODULO 1 → prog`,位置 `GROUND+(1-prog)*FALL_SPAN`;触地取模回卷,放弃"真物理自由落体"与"贴地淡出"。

- 问题:几何节点做 5 万片雪花持续下落,先后踩多个坑:
  - **速度要真实**(0.3~0.6 m/s 枝晶雪花末速度):`30m 高度 ÷ 60s ≈ 0.5 m/s`,不是"下雨式"快速下坠
  - **雪花刚出生悬在最顶一堆、下面空**——相位不随机会话导致"等开场"
  - **未到地面就消失**——曾用 `MapRange` 把底部淡出,视觉上雪花半空蒸发,应去掉,触地直接用取模回卷(prog 从~1 跳到 0 = 回天空)
  - **顶部堆积/分布成线性**——多 RandomValue 共用默认 ID 导致坐标相关,必须显式接 `Index` 作 ID + 各维度独立种子
- 根因:下落本质是"时间→相位→高度的循环映射",不是物理堆积;随机源若不绑定到具体点(Index)就退化成同一随机值
- 解决:见 `docs/雪花下落系统.md` §5,脚本 `scripts/snowfall-scatter/`;`verify_snow.py` 断言 3 帧实例数==50000 且 Z 贴地[-1.30, 28.70]
- 预防:
  - **宿主变换必须清零**(loc/rot/scale):落雪区高度锚定地平面,宿主被移(Z=-1.47)→ 雪埋进地面
  - 触地回卷用 `FLOORED_MODULO`,`别加贴地淡出`
  - 点阵按世界包围盒算位置:每个 RandomValue 都显式接 Index 作 ID、给独立 Seed
