# 星芒散射光效系统（多尖角星芒散布 + 控制器参数化 + 相机朝向）

> 来源：星芒工程实战（Blender 5.2 远程 9878 桥工程，Eevee 渲染）
> 适用：Blender 5.2 LTS，Eevee + AgX + Bloom
> 关键词：几何节点、Instance on Points、Object Info、billboard、EMPTY 控制器、自定义属性驱动、循环关键帧动画

---

## 零、一句话

把一套「**参数化星芒 + 沿相机朝向的亮片散射**」做成一坨可复用的**数据块集合 + 控制空物体**：
调整 `星芒_控制器` 上 6 个中文滑块即可改形状、大小、动画；散布在三个点云宿主上，每个实例始终朝向相机。

---

## 一、场景

在活动场景中需要一组**闪烁的发光星芒亮片**，要求：

- 多个星芒（中央圆盘 + 6 个尖角）成片散布，有视觉厚度/层次
- 每个星芒**始终朝向相机**（billboard），不随视角翻转变扁
- 星芒形状（尖角长度 / 圆盘半径 / 基部半角 / 内凹程度）与**整体大小、脉冲动画**都能统一控制
- 只渲染散布出来的星芒，**源对象本尊不渲染**（源用于生成几何，不留在画面）


## 二、总体架构

核心思想：**「源对象」负责生成星芒几何（被隐藏），「散布节点组」负责把该几何实例化到点云各点并做朝向/缩放/偏移**。源对象缩放被散布实例继承，因此控制器一个参数就能同时控所有星芒的大小。

```
星芒(源, hide_render=True, 单面平面)
  └─ NODES 修改器「星芒_GN」  → 平面被生成成多尖角星芒几何(4 形状参数 socket)
  └─ 6 条驱动                 → Socket_0..3 由形状参数驱动; scale 由 实际大小/1000 驱动

球心_点云 / 2 / 3(宿主 MESH, 提供散布点位)
  └─ NODES 修改器「星芒_散布_GN 系列」 → 每宿主一组: 读「星芒」几何实例化 →
       沿相机朝向对齐 + 场景时间错相缩放 + 位置偏移
  └─ NODES 修改器「小球_分布_GN 系列」(可选, 小球/星芒可并存, 见 §七)

星芒_控制器(EMPTY, 6 中文滑块 + 循环动画)
  ↳ 驱动「星芒」4 形状 socket 与整体 scale
空物体(EMPTY, 挂在相机下 → 朝向参考)
  ↳ 散布节点组经 ObjectInfo(RELATIVE) 读它, 让每个实例对齐到朝向
```

调用链：`星芒_控制器.实际大小/形状参数` → `星芒`(源) 修改器 socket + scale → 散布节点组读源几何 → 点云各点实例化 → 朝向/缩放/偏移 → 渲染。

## 四、控制器参数 → 驱动映射

`星芒_控制器` 的 6 个中文自定义属性（键名即显示名，[技能 `材质参数统一控制器` 同款约定](材质参数统一控制器与实时面板.md)）：

| 参数 | 默认(实况) | 作用 | 驱动目标 |
|---|---|---|---|
| `尖角长度` | 96.0 | 星芒尖角长度 | `星芒` 修改器 `星芒_GN` `Socket_0` |
| `圆盘半径` | 12.0 | 中央圆盘半径 | `Socket_1` |
| `基部半角` | 5.0(接口默认13) | 尖角基部半角 | `Socket_2` |
| `内凹程度` | 1.0 | 尖角内凹程度 | `Socket_3` |
| `实际大小` | 5.0 | 星芒整体大小基准 | 源 `星芒` `scale` = `实际大小/1000`（正确式应 `+ 动态缩放/1000`，见 §七坑②） |
| `动态缩放` | -0.45（动画）| 循环脉冲缩放（应叠加到整体大小） | 源 `scale`（当前仅 `实际大小` 生效） |

形状 4 参数用 **SCRIPTED 驱动**，表达式 `x`（SINGLE_PROP 变量指向控制器属性值）；整体大小用 `实际大小/1000`（当前）。`动态缩放_动画` 为 30 帧三角波关键帧（`(1,-0.45)→(16,0.1)→(31,-0.45)`）+ **CYCLES 循环修饰器**铺满 1–450 帧，写在控制器 Action 里。

读属性/驱动值时**必须走 depsgraph**（`dg.evaluated_get(obj).scale`），直接读内存对象可能拿到缓存值（[技能 `blender-bridge-ops`](../skills/blender-bridge-ops/) 铁律）。


## 五、几何节点结构

### 5.1 `星芒_GN` —— 源对象的形状生成器（41 节点）

挂在 `星芒` 源上的 NODES 修改器。把单面平面重建成星芒：

```
组输入(尖角长度/圆盘半径/基部半角/内凹程度)
  → 二次型贝塞尔×2 + 曲线圆环(Circle)        (6 尖角骨架 + 中央圆盘)
  → 填充曲线/点转曲线/重采样/设置样条线闭合/曲线转点
  → 实例化于点上 × 旋转实例(ROTATE_INSTANCES) (尖角沿圆环阵列)
  → 实现实例(REALIZE) → 合并几何体 → 设置材质(Set Material→星芒_金色)
  → 组输出(Geometry)
```

接口输入：`尖角长度=96`、`圆盘半径=12`、`基部半角=13`、`内凹程度=1.0`、`动态缩放=1.0`（末 socket 当前未连线，用默认 1.0）。**「动态缩放」接口输入与「实际大小」是两套作用点**：`实际大小`走对象 scale（继承给实例），接口里的 `动态缩放` 属星芒_GN 内部预留。

### 5.2 `星芒_散布_GN` 系列 —— 散布器（32 节点 ×3 份，结构相同）

三宿主各一份独立节点组（`星芒_散布_GN`=点云2、`_3`=点云3、`_4`=点云），差异只在**位置偏移**方向。

接口：`Geometry`(出入) + `生成数量`(Int, 默认 50)。

主链：

```
组输入.Geometry(宿主点云)
  → 网格转为点(MeshToPoints)
  → 随机值+编号 → 运算(阈值) → 分离几何体(Selection 筛选)
  → 设置位置.002(SET_POSITION, Offset=合并XYZ.002 位置偏移)
  → 实例化于点上(Instance=变换几何体←物体信息[星芒,RELATIVE],
                   Scale=合并XYZ.001, Rotation=对齐欧拉至矢量[空物体])
  → 实现实例(REALIZE) → 组输出
```

关键接线（探测实况）：

| 输入 | 来源 | 含义 |
|---|---|---|
| IOP.Instance | 变换几何体 ← **物体信息(星芒)** space=**RELATIVE** | 取源星芒几何（带动画/缩放）当实例 |
| IOP.Scale | **合并XYZ.001**（X/Y/Z ← 运算.007） | 场景时间→运算链错相缩放 |
| IOP.Rotation | **对齐欧拉至矢量 ← 物体信息(空物体)** | 每个实例朝向相机下的空物体（billboard） |
| IOP.Selection | 未接线 | 数量筛选在分离几何体处做死 |
| SET_POSITION.002.Offset | **合并XYZ.002** | 施加在实例化**之前**的点上，避免被实例缩放放大 |

三组的位置偏移（合并XYZ.002 常量，X/Y/Z）：

| 节点组 | 宿主 | 偏移 |
|---|---|---|
| `星芒_散布_GN` | 球心_点云2 | (-0.0065, **-0.0076**, 0) |
| `星芒_散布_GN_3` | 球心_点云3 | (-0.0065, 0, **-0.0076**) |
| `星芒_散布_GN_4` | 球心_点云 | (-0.0065, **+0.0076**, 0) |

另有 `合并XYZ`（X/Y/Z=**0.12**）作星芒实例**基准缩放**常量。

### 5.3 缩放动画链（场景时间 → 错相）

实例缩放走 **Scene Time → SINE → MULTIPLY → ADD 运算链 → COMBXYZ.001 → IOP.Scale**，配合随机值给每点不同相位，实现**颗颗错峰脉动**（Geometric Nodes 里做，依赖 SceneTime，独立于对象级 scale 驱动）。源对象级 scale 再由控制器 `实际大小` 统一放大——两层相乘得出最终尺寸。

### 5.4 材质

- `星芒_金色`（散布星芒可见材质）：Emission **Color=(1,1,1,1) 白**，**Strength=5**。改色直接改它。
- `星芒_发光`：源网格材质槽，无发光节点（源已隐藏，不参与画面；历史遗留）。


## 六、使用说明（复用步骤）

### 6.1 迁到新工程

1. 只读/复制源工程，连带拷走：集合 `星芒_效果`（7 对象）+ §三依赖的数据块（4 节点组 + 2 材质 + Action）。
2. 把 `空物体` 重新挂到**目标相机**下（billboard 参考）。
3. 确认 **Eevee** 渲染 + **Bloom**，`material_override=None`。

### 6.2 日常调整

| 想改什么 | 改哪里 |
|---|---|
| 星芒颜色 | `星芒_金色` 的 Emission Color |
| 尖角长度/圆盘半径/基部半角/内凹 | `星芒_控制器` 对应滑块 |
| 整体大小基准 | `星芒_控制器.实际大小`（源 scale `/1000`）|
| 循环脉冲（强）| 源 scale 驱动表达式含 `动态缩放`（见 §七坑②）+ 控制器 `动态缩放_动画` |
| 散布数量 | 各散布节点组接口 `生成数量`（修改器面板）|
| 星芒位置 | 对应节点组 `合并XYZ.002`（位置偏移）|
| 实例朝向 | 移 `空物体`（挂在相机下，跟着机位走）|
| 隐藏/显示源本尊 | `星芒.hide_render`（True=只出散布，False=源也出现在原位）|

### 6.3 用脚本审计状态 / 修复 scale 驱动

见可复用脚本包 [scripts/starburst-scatter/](../scripts/starburst-scatter/)（`probe_star.py` / `verify_star.py` / `fix_star_scale.py`）：
- `probe_star.py`：只读 dump 控制器 6 参数、源驱动/scale 表达式、三宿主散布偏移、生成数量。
- `verify_star.py`：独立核验关键不变量（源隐藏渲染、ObjectInfo 空间、偏移、scale 表达式、控制器动画关键帧）。
- `fix_star_scale.py`：把源 scale 3 条驱动表达式重置为 **`实际大小/1000 + 动态缩放/1000`**（幂等，恢复控制器 `动态缩放` 对整体大小的影响）。


## 七、注意事项（坑）

1. **源隐藏渲染，散布照常**：`星芒.hide_render=True` / `visible_camera=False`，但散布实例走节点组评估，**不受影响**（保留 `hide_viewport=False`，视口可继续看到生成用的源几何）。
2. **scale 驱动表达式的先后版本**：正确完整式是 `实际大小/1000 + 动态缩放/1000`（`动态缩放` 参与整体大小）。**实况已退化为只 `a/1000`**（`b` 变量在但未进表达式）→ 控制器上的 `动态缩放_动画` 目前不影响大小。若要脉冲动画生效，用 `fix_star_scale.py` 恢复，或直接改表达式。核验时读**评估** scale，确认 `实际大小×?`。
3. **Object Info 必须 RELATIVE**：`物体信息(星芒)` 用 RELATIVE 才能继承源对象 scale（`实际大小` 参数由此对每个实例生效）；改成 ORIGINAL 会**忽略源缩放与动画**（源 scale 驱动形同虚设）。
4. **位置偏移要放在实例化之前**：用 `设置位置(SET_POSITION)` 施加在分离后的**点**上、再进 `实例化于点上`；若直接给 IOP 的 Position/Scale 改，偏移会被实例基缩放大、方向错乱。
5. **生成数量不走空对象属性驱动**：Blender 5.2 里用 EMPTY 自定义属性去驱动几何节点 socket **不可靠**（depsgraph 读缓存值，如 288.0）。`生成数量` 在**散布节点组接口/修改器面板**调，实时生效。
6. **朝向只沿这个空物体**：`对齐欧拉至矢量` 读 `物体信息(空物体, RELATIVE)`，`空物体` 必须**挂在相机下**（随机位走）；别直接指向相机（相机不在节点树几何内）。几何节点里实例的朝向，**对象级 DAMPED_TRACK 等约束不作用于实例化对象**——必须在几何节点内做（[仓库相关原则](驱动式Z轴匀速旋转系统.md)同源）。
7. **多份散布用独立节点组**：三个宿主各一份独立散布组（不是复制修改器引用同名组），各自偏移/数量隔离，改一处不串扰。修改器 input 不可迭代（`mod.properties.inputs` 是 `GeometryNodesInterfaceInputs`，访问用 `.get(名字)` / 属性访问，`enumerate(...)` 会抛异常）。
8. **细节联动**：源 `星芒` 是 1 面平面+GN 修改器生成形状——改源材质/几何请在修改器/材质里改，别在源平面布线；删源会断散布。`星芒_金色` 认定颜色以**接在 Active Output 上的 Emission** 为准。控制器 `动态缩放` 键名即中文 UI（键即显示名）。
9. **写/验分两次请求**：同一次 exec 里改完立即读会拿到刷新前的缓存；改后 `obj.update_tag()` + `view_layer.update()`，另起一次请求核验（桥 120s 超时先用 powershell 不带 BOM 落盘）。
10. **备份先行**：对 `.blend` 的修改（尤其驱动、修改器）先做带时间戳备份；`fix_star_scale.py` 只改驱动表达式、幂等，可安全重跑。

## 九、Blender 5.2 API 坑速查

| 问题 | 说明 |
|---|---|
| `mod.properties.inputs` 不可迭代 | 5.2 返回 `GeometryNodesInterfaceInputs`，`enumerate(...)` 抛错；用 `.get(名)` / 属性访问 |
| EMPTY 属性驱动几何 socket 不稳 | 驱动读缓存值（如 288.0）；量化参数放节点组接口/修改器面板 |
| 几何节点实例不受对象级朝向约束 | 实例朝向必须几何节点内 `ALIGN_EULER_TO_VECTOR` |
| ObjectInfo ORIGINAL 忽略源缩放 | 要继承源 scale/动画用 **RELATIVE** |
| 读被驱动值 | 必须 `evaluated_depsgraph_get()` 后 `evaluated_get`，不能直接读内存属性 |
