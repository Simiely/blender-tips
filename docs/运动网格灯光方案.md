# 运动网格灯光方案 · Blender 5.2

> 给「带驱动上下浮动」的网格，在每个轴心自动加一对 AREA 灯（向下照 + 向上照），
> 灯跟随网格运动、可手动偏移微调、旋转联动。
> 可复用脚本见 `scripts/driver-lights/build_light_system.py`。

## 场景

- 主装置/机械臂带 bob 上下浮动驱动，想在每个运动单元加装饰灯；
- 要两组灯：一组朝下照、一组朝上照（背靠背，亮度不同）；
- 灯要跟着网格一起动（网格浮动灯也浮动）；
- 偶尔微调某盏灯的位置/角度，但不脱离跟随。

## 原理

1. **建灯**：每个运动网格轴心建 2 盏 AREA 灯——向下（rot_x=0）亮度 1.5 倍、
   向上（rot_x=π）亮度 2 倍、z 略抬 0.001。
2. **打组**：每集合建「`集合名_灯向下/向上_轴心`」空对象（放在集合运动中心），
   灯 parent 到轴心 → 方便整体管理/旋转。
3. **跟随**：灯挂 location 驱动 `v + 偏移`，v = 网格 `location[0/1/2]`（SINGLE_PROP）。
   网格 bob 浮动 → 灯自动跟随，偏差为零。
4. **手动偏移**：每盏灯带 `偏移X/Y/Z` 属性，驱动表达式 `v + light_off(self, 轴)`，
   `light_off` 实时读自身偏移 → 手动调偏移不被驱动覆盖、运动后保留。
5. **旋转绑定**：向上灯为主（无驱动，自由转），向下灯驱动 = 向上灯旋转 + (−π,0,0)
   → 转向上灯，向下灯自动同步（保持 180° 朝向差）。

## 做法

```bash
python send.py build_light_system.py   # 或 Scripting 工作区 Run Script
```

改顶部 `TARGETS` 指定集合列表，脚本自动完成建灯/分组/跟随/偏移/旋转绑定。

## 验证方法

```python
# 抽查一盏灯跨帧是否跟随网格
scene.frame_set(f); dg.update()
lz = light.evaluated_get(dg).matrix_world.to_translation().z
mz = mesh.evaluated_get(dg).matrix_world.to_translation().z
assert abs(lz - mz) < 1e-4   # 向下灯
assert abs(lz - mz - 0.001) < 1e-4  # 向上灯
```

## ⚠️ 坑(实战踩的)

- **新建轴心空物体后必须 `view_layer.update()` 再读 `matrix_world`**：
  否则读到的还是单位矩阵 → `matrix_parent_inverse` 设成 identity →
  灯世界坐标 = 轴心 + 网格位置（整体翻倍偏移跑出集合）。这是最常见的大坑。
- **5.2 `DriverTarget` 无 `array_index` 属性**：SINGLE_PROP 读数组分量用
  `data_path='location[0]'` 带下标，不是设 array_index。
- **脚本改偏移属性不触发驱动重算**（depsgraph 缓存），UI 手动改/打关键帧正常。
  因此用命名空间函数 `light_off` 实时读，避免 SINGLE_PROP 缓存。
- **驱动单向**：A↔B 互指会循环报错。旋转联动只能"一主一从"，主灯自由、从灯驱动跟随。
- 运行后 Ctrl+S 保存；`light_off` 是命名空间函数，重开文件后需恢复（restore_drivers）。

## 调试建议

- 灯跑偏 → 检查 `matrix_parent_inverse` 是否为 `父.matrix_world.inverted()`（非 identity）；
- 灯不动 → 检查 location 驱动是否在、变量是否指向正确网格；
- 想换主从 → 把旋转驱动从"从灯"移到"主灯"，偏移量取反。
