# 几何节点泡泡发射系统（发射口喷射 + 圆形范围约束 + 出生门控 + 消散 + 慢速倍率）

> 来源：9666 桥工程实战（Blender 5.3，`气泡生成.blend`）
> 适用：Blender 5.3，几何节点 + 远程桥；网格 `泡泡范围` 为水平圆形面
> 关键词：Geometry Nodes、Mesh Line、Scene Time、FLOORED_MODULO、Set Position、Instance on Points、Object Info、Bound Box、SINGLE_PROP、depsgraph

## 零、一句话

把「从空对象发射泡泡」做成一个可复用的 **控制器 + 隐藏源球 + 几何节点系统**：

- 泡泡从 `发射口` 出生
- 水平分布目标贴合 `泡泡范围` 的正圆
- 高度走先升后降的循环曲线
- 每个泡泡有独立出生帧、消散帧和随机大小
- 全部参数由中文滑块驱动

脚本包：`../scripts/geometry-node-bubble-emitter/`
Agent Skill：`../skills/blender-gn-bubble-emitter/SKILL.md`

## 一、场景

在场景中需要一个类似气泡发射的效果：

- 空对象 `发射口` 是发射原点，朝世界 `+Z`
- 网格 `泡泡范围` 是水平圆形面，作为泡泡的 XY 活动边界
- 泡泡要扩散开，先上飞再下落，不能越出圆形范围
- 出生前不能有泡泡；出生后逐个出现，不要整团弹出
- 落地前要缩小淡出，不能满尺寸瞬间跳回发射口
- 下落阶段要能随机提前消散
- 整体速度要能用参数调节，不再改节点内部常量

## 二、总体架构

核心思想：**用点 ID 表示泡泡，用场景帧计算每个泡泡的生命周期比例，再公式化生成位置，最后实例化球体。**

```text
泡泡控制（中文属性）
  └─ SINGLE_PROP 驱动节点内 Value

发射口 ObjectInfo ─┐
泡泡范围 ObjectInfo ─┼─ 位置公式 / 圆形边界 / 时间循环 → Set Position → Instance on Points
源球 ObjectInfo ────┘
```

调用链：

```text
控制器参数 → 节点内 Value → 生命周期/半径/扩散/倍率 → 泡泡点位置与缩放 → 球体实例
```

## 三、对象与数据块清单（都在「泡泡系统」集合）

| 对象 | 型别 | 关键配置 | 作用 |
|---|---|---|---|
| `泡泡控制` | EMPTY | 11 个中文滑块，带 `min/max` | 参数总控 |
| `泡泡_源球` | MESH | `hide_render=True`、`hide_set(True)`、半透明材质 | 实例化用的源球，本体不渲染 |
| `泡泡发射_系统` | MESH | 空网格 + NODES 修改器 | 生成并输出泡泡实例 |
| `发射口` | EMPTY | 世界 +Z 朝上 | 发射原点，不修改 |
| `泡泡范围` | MESH | 水平圆面，半径约 5.5 | 边界来源，不修改 |

依赖的数据块：节点组 `泡泡发射_GN`、材质 `泡泡_半透明材质`。

## 四、控制器参数到驱动映射

`泡泡控制` 的中文自定义属性（键名即显示名）：

| 参数 | 默认/实况 | 作用 | 驱动目标 |
|---|---:|---|---|
| `泡泡数量` | 600 | 实例数量 | `生成泡泡点.Count` |
| `泡泡半径` | 0.03 | 单个泡泡半径 | `泡泡缩放` |
| `扩散半径` | 4.1 | 旧发射口扩散半径；`范围匹配=0` 时使用 | 旧目标半径 |
| `上升高度` | 1.0 | 高度曲线抬升量 | `上升项` |
| `生命周期` | 96 | 基础生命周期帧数 | 有效生命周期 |
| `起始帧` | 0 | 发射起始帧 | 出生帧 |
| `随机种子` | 1 | 相位/方向/大小/消散随机种子 | 四个 Random Value |
| `边界余量` | 0.15 | 泡泡与范围边界的安全留白 | 允许半径 / 落地 Z |
| `范围匹配` | 1.0 | 0=发射口扩散，1=匹配泡泡范围圆 | 目标中心/半径混合 |
| `下落消散` | 0.35 | 下落阶段随机提前消散比例 | 消散标记 |
| `顶点比例` | 0.5 | 高度曲线顶点位置；0.5=对称 | 高度时间重映射 |
| `慢速倍率` | 2.5 | 整体时间倍率；越大越慢 | 有效生命周期 |

实际生命周期：

```text
有效生命周期 = 生命周期 × 慢速倍率 = 96 × 2.5 = 240 帧
```

驱动方式：全部用 `SINGLE_PROP` 指向 `泡泡控制["参数名"]`，表达式 `v`，挂在节点组内 `Value` 输出上。不要驱动修改器 socket。

## 五、几何节点结构

### 5.1 主链（153 节点 / 239 连线）

```text
Mesh Line
  → Set Position（公式化位置）
  → Instance on Points（源球实例 + 随机缩放 + 显隐）
  → Group Output
```

关键点：`Instance on Points` 没有 `Position` 输入。必须先 `Set Position` 再实例化。

### 5.2 时间循环

```text
Scene Time.Frame
  → 帧减起始
  → 帧减相位（相位 = Random × 有效生命周期）
  → FLOORED_MODULO(有效生命周期)
  → q = age / 有效生命周期
```

普通 `MODULO` 在负数时会裁剪，出生前会回卷出泡泡。必须用 `FLOORED_MODULO` 并配合出生门控。

### 5.3 高度曲线

```text
q → 高度时间重映射(顶点比例) → qz
z = 发射口Z + 上升高度×sin(π×qz) - 下落量×qz²
```

`顶点比例=0.5` 时是对称上升/下降；小于 0.5 会让顶点提前、下降段变长。整体速度由 `慢速倍率` 控制，而不是靠顶点比例硬拉。

### 5.4 圆形范围匹配

从 `泡泡范围` 的 ObjectInfo → Bound Box 得到 `Min/Max`：

```text
圆心 = (Min + Max) / 2
范围半径 = min(宽, 高) / 2
允许半径 = 范围半径 - 泡泡半径 - 边界余量
```

目标点由 `范围匹配` 在两套中心之间混合：

- `0`：以 `发射口` 为中心，半径用 `扩散半径`
- `1`：以 `泡泡范围` 圆心为中心，半径用 `允许半径`

最终位置：

```text
终点 = 混合中心 + 方向 × 目标半径 × Random
位置 = 发射口 + (终点 - 发射口) × smoothstep(q)
```

外层仍保留一道以圆心为基准的径向钳制，作为安全兜底。

### 5.5 出生门控

```text
出生帧 = 起始帧 + 随机相位 × 有效生命周期
已出生 = frame > 出生帧 - 0.5
```

`已出生` 接到 `Instance on Points.Selection`。出生前完全无实例；出生后从 `q=0` 开始。

### 5.6 淡入淡出与下落随机消散

每个泡泡有独立死亡点：

```text
消散标记 = Random(0..1) < 下落消散
随机死亡点 = Random(0.55..0.95)
死亡比例 = 1 - 消散标记 × (1 - 随机死亡点)
```

未命中的泡泡死亡比例为 `1`，在生命周期末端自然淡出；命中的泡泡在过顶点后提前消散。

缩放淡隐：

```text
淡入 = smoothstep(min(q / 0.08, 1))
淡出 = smoothstep(clamp((死亡比例 - q) / 0.08, 0, 1))
最终缩放 = 泡泡半径 × 随机大小 × 淡入 × 淡出
```

这样落地前缩到 0，不会满尺寸从地面跳回发射口；随机消散也不是硬消失。

### 5.7 核验方法

另起请求重新取引用，用 `depsgraph.object_instances` 收集实例矩阵：

| 帧 | 实测数量 | 意义 |
|---:|---:|---|
| 1 | 0 | 起始帧前无泡泡（当起始帧>0 时） |
| 20 | 50 | 慢速倍率 2.5 时的出生节奏 |
| 60 | 148 | 持续增长 |
| 150 | 383 | 接近稳态 |
| 300 | 548 | 稳态，随机消散后 |

把 `慢速倍率` 临时改成 `1.0`，第 20 帧变成 123 个，证明倍率真实驱动了生成节奏。

## 七、注意事项（坑）

1. **`Instance on Points` 没有 `Position` 输入**：必须先用 `Set Position` 设置点位置，再实例化。
2. **同一脚本内改自定义属性后驱动看似无效**：必须 `ctrl.update_tag(refresh={"OBJECT"})` + `ng.update_tag()` + `view_layer.update()`；UI 手动调节不受影响。
3. **先探 API 再写节点脚本**：Blender 5.3 的 socket 名称和节点属性不能凭记忆猜，用 `probe_gn_api.py` 先落盘。
4. **原生 `MODULO` 负数会回卷**：出生前会出现泡泡；必须 `FLOORED_MODULO` + 出生门控。
5. **生命周期回卷会造成地面突跳**：必须两端淡隐缩放，不能让满尺寸泡泡在落地帧跳回发射口。
6. **圆形范围的圆心不是发射口**：发射口相对圆心有偏移，扩散半径不能直接取范围半径。
7. **随机消散不是瞬时全杀**：死亡点在 `0.55–0.95`，泡泡死亡前仍显示约 75% 周期，同一帧只会少约 9%（`下落消散=0.35` 时）。
8. **`范围匹配=0` 可回退旧行为**：排查新问题时先切到 0 做 A/B。
9. **桥只改内存**：所有改动后提醒用户 Ctrl+S。
10. **源球不能可见**：`hide_render` 与 `hide_set` 都要设置，否则会多出一个大球。

## 九、Blender 5.3 API 坑速查

| 问题 | 说明 |
|---|---|
| `GeometryNodeInstanceOnPoints` 无 `Position` | 用 `GeometryNodeSetPosition`，再接 `Points` |
| `FunctionNodeRandomValue` 类型值 | `FLOAT` 可用；`VECTOR` 不存在，需 `FLOAT_VECTOR` |
| `ObjectInfo.As Instance` | 源球实例设为 True，范围几何设为 False |
| `Bound Box.Min/Max` | 用来取圆形范围的中心与半径 |
| `ShaderNodeMath.FLOORED_MODULO` | 必须用，普通 `MODULO` 负值裁剪 |
| 节点 socket 驱动 | 挂在 `Value.outputs[0].default_value` 上，用 `driver_add` |
| 同进程依赖图刷新 | 改属性后必须 `update_tag`，否则读到旧值 |
| 实例核验 | 用 `depsgraph.object_instances`，按源球名筛选 |
