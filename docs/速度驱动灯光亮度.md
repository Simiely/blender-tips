# 速度驱动灯光亮度 · Blender 5.2

> 把灯的亮度接到「目标物体 Z 轴运动速度」上:物体上移(向 +Z)灯光增强、下移(向 −Z)
> 衰减,让灯光"随运动呼吸"。本方案已抽象为通用脚本包 `scripts/speed-light/`。

## 场景

- 有物体带上下浮动驱动(如柱子的 bob 浮动),想在每个运动单元上让灯光亮度跟着运动节奏变化;
- 灯位置要**固定**在物体轴心(否则亮度变化被位移淹没),只让亮度随速度变;
- 不同尺寸/高度的物体,需要不同的亮度范围与变化幅度(短柱不必像长柱那么亮)。

## 原理

1. **速度用前向差分**求:`v = pos(frame+1, target) − pos(frame, target)`,单位 = 长度/帧。
   - `pos` 是命名空间位置函数(默认 `bob`),**不是**目标的当前 `location` —— 避免驱动求值
     顺序读到未刷新的旧帧值导致滞后/抖动。
2. **亮度 = 速度的线性函数**:
   - 上移(向 +Z,`v ≥ 0`):`e = BASE + K_UP · v`
   - 下移(向 −Z,`v < 0`):`e = BASE − K_DOWN_RATIO · K_UP · |v|`
3. **clamp 到 `[E_MIN, E_MAX]`**:下移倍率 + 放大系数可能让 energy 溢出,必须限幅。
4. **按目标特征分档(TIERS)**:短柱速度小、体量小 → 小系数 + 低上限;长柱 → 大系数 + 高上限。

## 实操参数(本仓库实战值)

- 基础亮度 `BASE = 6`(即灯的静态 Energy 设为 6)
- 上下移比例:`K_DOWN_RATIO = 2`(下移衰减是上移增强的 2 倍速度斜率)
- 分档(`目标 dimensions.z < 2.0` 判定短/长柱):

| 档 | 命中条件 | K_UP(放大系数) | E_MAX(亮度上限) |
|---|---|---|---|
| 短柱 | `z < 2.0` | 1700 | 20 |
| 长柱 | 兜底 | 3400 | 100 |

- 实测目标 Z 速度范围:主装置 01~05(700–1465 帧)约 **±0.027 ~ ±0.030 米/帧**。

## 核心逻辑与要点(重启自愈)

与其它命名空间函数驱动一致(见天空太阳驱动文档):函数**源码以文本块随 .blend 保存**,运行期
`driver_namespace` 映射不落盘,靠文本块勾 **Register** + 偏好设置 **Auto Run Python Scripts**

## 挂驱动写法

灯的 `energy` 挂 SCRIPTED 驱动,表达式 `speed_energy(pname, fr)`,两个 SINGLE_PROP 变量:

- `pname` → 灯数据 `["energy_panel"]`(记录跟踪的柱目标名)
- `fr` → `scene.frame_current`

```python
drv = ld.driver_add('energy').driver
drv.type = 'SCRIPTED'
drv.expression = 'speed_energy(pname, fr)'

v1 = drv.variables.new(); v1.name = 'pname'; v1.type = 'SINGLE_PROP'
v1.targets[0].id_type = 'LIGHT'; v1.targets[0].id = ld
v1.targets[0].data_path = '["energy_panel"]'

v2 = drv.variables.new(); v2.name = 'fr'; v2.type = 'SINGLE_PROP'
v2.targets[0].id_type = 'SCENE'; v2.targets[0].id = scene
v2.targets[0].data_path = 'frame_current'
```

完整可幂等脚本见 `scripts/speed-light/build_speed_light_drivers.py`。

## 踩坑速记

- **放大系数要上千倍**:速度是"米/帧"级小数,系数 150 时 0~10 都看不出变化;1700~3400 才能
  推到可见的几十~上百。调参顺序:先定亮度范围,再按实测速度反推 `K_UP ≈ 幅度 / 速度极值`。
- **位置必须恒定**:灯跟随目标运动会让位移盖过亮度变化;先定到轴心(朝上的灯 +0.01 cm)再挂驱动。
- **速度别用 `frame−1` 后向差分**、也别读目标 `.location`(相位/缓存问题,见原理 1)。
- **必须 clamp** 到 `[E_MIN, E_MAX]`,否则下移时 energy 可能变负数或爆炸。
- 运行后 **Ctrl+S** 保存。
