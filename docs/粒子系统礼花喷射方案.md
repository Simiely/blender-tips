# 粒子系统礼花喷射方案（金纸礼花/Confetti Cannon）

> 来源：`260827x07_合并260826x03.blend` 实战
> 适用：Blender 5.2 LTS，Eevee 渲染
> 关键词：粒子系统、礼花、金纸、Confetti、湍流、碰撞杀死

---

## 一、场景

需要在活动场景中制作**持续向上喷射的金色纸片礼花效果**，要求：

- 多个发射点，沿 Z 方向持续喷射金色纸片
- 纸片有形状随机性（方形、长条、圆片、三角等）和弯曲感
- 上升后缓慢飘落，带有空气阻尼和噪波扰动
- 粒子低于指定高度时自动消失（碰撞杀死）
- Eevee + Bloom 发光

## 二、原理

使用 **Blender 粒子系统（EMITTER）** 实现持续喷射：

1. **发射器**：一个平面网格，旋转方向决定粒子初始喷射方向
2. **粒子系统**：EMITTER 模式，持续发射，受重力和阻尼影响
3. **渲染**：使用 COLLECTION 渲染，粒子实例为多种弯曲纸片形状
4. **湍流场**：TURBULENCE 力场，让粒子下落时有随机扰动
5. **碰撞杀死**：在指定高度放置碰撞平面，启用 `use_particle_kill`，粒子触碰即消失

## 三、做法

### 3.1 准备工作

1. 在场景中创建空对象作为发射点，名称如 `发射点，方向Z向_01`
2. 创建空对象 `杀死粒子`，放置在纸片应该消失的高度位置
3. 确保场景使用 Eevee 渲染引擎

### 3.2 创建纸片形状

需要创建 14 种纸片变体（6 种形状 × 2~3 种弯曲方向），全部放入一个集合，供粒子系统实例化。

```python
import bpy
from mathutils import Vector

def make_bent_shape(name, primitive, scale_xyz, bend_angle):
    """创建形状 -> 缩放 -> 弯曲 -> 加材质"""
    bpy.ops.object.select_all(action='DESELECT')
    if primitive == 'cube':
        bpy.ops.mesh.primitive_cube_add(size=1.0, location=(0,0,0))
    elif primitive == 'cylinder':
        bpy.ops.mesh.primitive_cylinder_add(vertices=12, radius=0.5, depth=1.0, location=(0,0,0))
    elif primitive == 'cylinder3':
        bpy.ops.mesh.primitive_cylinder_add(vertices=3, radius=0.5, depth=1.0, location=(0,0,0))
    obj = bpy.context.object
    obj.scale = scale_xyz
    bpy.ops.object.transform_apply(scale=True)
    obj.name = name
    if abs(bend_angle) > 0.01:
        mod = obj.modifiers.new(name="Bend", type='SIMPLE_DEFORM')
        mod.deform_method = 'BEND'
        mod.deform_axis = 'X'
        mod.angle = bend_angle
    return obj
```

缩放参数参考：
- 方形纸片：`(0.15, 0.12, 0.02)`
- 长条彩带：`(0.25, 0.06, 0.02)` / `(0.3, 0.04, 0.015)`
- 圆片：`(0.08, 0.08, 0.015)`
- 宽条：`(0.12, 0.18, 0.02)`
- 三角片：`(0.08, 0.08, 0.015)`

弯曲角度参考：0.3~0.7 弧度（Simple Deform Bend），正负方向各一份。

### 3.4 创建发射器与粒子系统

```python
# 创建发射器平面
bpy.ops.mesh.primitive_plane_add(size=0.5, location=launch_pos)
emitter = bpy.context.object
emitter.name = "礼花_01_emitter"
emitter.rotation_euler = (0, 0, 0)  # Z向上

# 添加粒子系统
emitter.select_set(True)
bpy.context.view_layer.objects.active = emitter
bpy.ops.object.particle_system_add()
ps = emitter.modifiers[-1].particle_system
pset = ps.settings
```

| 参数 | 值 | 说明 |

### 3.7 碰撞杀死平面

```python
kill_pos = bpy.data.objects.get("杀死粒子").location
bpy.ops.mesh.primitive_plane_add(size=6.0, location=kill_pos)
kill_plane = bpy.context.object
kill_plane.rotation_euler = (0, 0, 0)
mod = kill_plane.modifiers.new(name="Collision", type='COLLISION')
col = mod.settings
col.use_particle_kill = True
col.permeability = 0.0
col.damping = 1.0
col.stickiness = 0.0
col.thickness_outer = 0.0
```

### 3.8 合成器 Bloom

```python
scene.use_nodes = True
tree = scene.compositing_node_group
nodes = tree.nodes; links = tree.links
rl = nodes.new('CompositorNodeRLayers')
glare = nodes.new('CompositorNodeGlare')
glare.inputs['Threshold'].default_value = 0.15
glare.inputs['Strength'].default_value = 4.0
glare.inputs['Size'].default_value = 12
display = nodes.new('CompositorNodeConvertToDisplay')
links.new(rl.outputs['Image'], glare.inputs['Image'])
links.new(glare.outputs['Image'], display.inputs['Image'])
scene.render.use_compositing = True
```

## 五、注意事项

### ⚠️ 粒子不显示
- 视口必须切换到 **Rendered** 着色模式（Solid 模式下粒子不可见）
- 粒子系统 `render_type` 必须设为 `COLLECTION` 或 `OBJECT`

### ⚠️ 粒子杀死不生效
- 碰撞平面必须在被杀死粒子下方
- `use_particle_kill` 必须为 True
- `thickness_outer` 建议设为 0（接触即杀）

### ⚠️ 发射方向不对
- 发射器平面的法线方向 = 粒子发射方向
- 平面旋转 `(0, 0, 0)` 时法线朝 Z 向上
- 如果发射点空对象有角度，可以将发射器旋转匹配空对象

### ⚠️ 崩溃后恢复
- Blender 崩溃后，发射点空对象位置可能保留
- 但粒子系统和发射器网格需要重新创建
- 参考本脚本包中的 `build_firework.py` 一键重建

## 七、Blender 5.2 API 坑速查

| 问题 | 说明 |
|------|------|
| 没有 `fcurves` 属性 | Blender 5.2 使用 Slotted Action，通过 `action.layers[].strips[].channels[].keyframes` 访问 |
| 碰撞属性 | `CollisionSettings` 中 `use_particle_kill` 控制粒子杀死，`friction` 属性不存在 |
| `view_layer.update()` 作用域 | 仅更新当前视图层，不影响粒子系统刷新 |
| 粒子显示 | 粒子系统在视口需要 Rendered 模式才可见 |
